# さきよみ — 家族のための準備室

入院が決まった人が普通の言葉で話すと、いつ・いくら要るかをプログラムが計算し、家族や窓口に渡す文章を Claude が下書きする Web アプリです。[Built with Claude: Japan 2026](https://cerebralvalley.ai/events/~/e/built-with-claude-japan2026) の提出作品で、テーマは 2「本来、誰にでも届くべきものを」（専門知識と手続きの壁）です。

| 誰の       | 入院が決まった本人と、その家族                                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| どんな課題 | 見積もりを受け取っても、制度を知らないと退院の日にいくら要るかを計算できない。同じ時期に、朝の支度や保険の確認を誰にどう頼むかも決めることになる        |
| どう解くか | 入力欄は 1 つ。話から Claude が条件を読み取り、金額と日付はプログラムが計算する。引き継ぎのメモと確認文はカードになり、自分で直して、渡すものだけ選べる |

作者自身が入院の準備で、いくら要るのか、誰に何を頼むのかを整理しようとしたことが出発点です。

## 試す

**https://sakiyomi-bwc2026.vercel.app** （ログインも API キーも要りません）

デモ動画（2 分 58 秒）: https://youtu.be/c-3mh5sisec

- 「まず、架空の体験例を見る」は回数の制限なく試せます。Claude を呼びません
- Claude との会話には上限があります。端末ごとに 1 日 20 回、全体で 1 日 150 回、短時間の連打は 1 時間 20 回までです。日本時間の 0 時に切り替わります。上限に達しても、入力とメモは画面に残ります（[ADR 0012](docs/adr/0012-open-production-with-usage-limits.md)）
- **実名や病名を書かず、架空の内容で試してください。** 送った内容はサーバーを経由して Anthropic へ送られます。アプリは本文を保存もログ出力もしません
- 回数はメモリの中で数えるので、厳密な上限ではありません。API の残高が尽きると会話は失敗し、体験例だけが動きます

試す文の例です。人物も金額も架空です。

> 12月14日に入院して、28日に退院する予定です。病院の見積もりだと、医療費は総額で80万円くらい。協会けんぽで、給料は月35万円くらいです。すぐ使えるお金は20万円。保険にも入っていて書類は青いファイルにあるけど、給付金がいつ入るのか分かりません。朝はいつも私が子どもの支度をしています。7時に起こして、着替えは寝室の白い棚、水筒はかばんの横、8時10分に家を出ます。夫に頼みたいけど、何をどう伝えればいいか。

続けて「入院が1週間延びて、退院が1月4日になったら？」と話すと、計算し直します。

## 何が返ってくるか

話した内容は、右側の「家族のしおり」にカードとして並びます。

| カード           | できるもの                                                             | 未確認として残すもの                 |
| ---------------- | ---------------------------------------------------------------------- | ------------------------------------ |
| お金の見通し     | 高額療養費の上限、食事代、営業日、手元資金をプログラムが計算した見通し | 見積もりと実際の請求の差、給付の有無 |
| 暮らしの引き継ぎ | 朝の支度など、話した手順を渡せる文章にしたもの                         | 担当する人の了承、話されていない手順 |
| 確かめる・頼む   | 保険会社や身近な人にそのまま見せられる質問文と依頼文                   | 給付の可否と額、相手の回答と同意     |
| 残しておく言葉   | 本人が残したいと話した言葉。原文のまま                                 | なし（書き足さない）                 |

自分で直したカード、「準備できた」にしたカード、渡すと選んだカードは、話を続けても上書きされません。「渡すメモに含める」を選んだものだけを確認画面で読み、コピーかテキストで保存します。会話の全文は入りません。送るのは本人です。

上の例をプログラムで計算すると、次のようになります。すべて架空の条件です。

| 条件（医療費の総額 80 万円、手元 20 万円）                 | 要る額     | 手元との差        |
| ---------------------------------------------------------- | ---------- | ----------------- |
| 2 週間（12 月内）、窓口で上限が効く                        | 115,690 円 | 84,310 円残る     |
| 2 週間（12 月内）、窓口で上限が効かない                    | 264,750 円 | 64,750 円足りない |
| 1 週間延びて月をまたぐ、費用が 12 月に寄る（60 万・20 万） | 185,240 円 | 14,760 円残る     |
| 1 週間延びて月をまたぐ、費用が半々（40 万・40 万）         | 210,180 円 | 10,180 円足りない |

高額療養費の上限は月ごとに掛かるので、総額が同じと仮定しても月をまたぐと要る額が増えます。

## なぜこの課題か

公開の調査で分かっているのは次のことです。

- 過去 5 年に入院した人の自己負担は平均 18.7 万円で、収入が減った人も 18.3%（平均 27.3 万円）います。入院した 675 人のうち、窓口で上限までを払った人が 49.6%、いったん払って後から払い戻しを受けた人が 17.9% でした（[生命保険文化センター 2025 年度調査 p.60〜64](https://www.jili.or.jp/files/research/chousa/pdf/r7/2025honshi_all-.pdf)）。後払いの場合、協会けんぽは払い戻しまで[診療月から 3 か月以上](https://www.kyoukaikenpo.or.jp/faq/benefit/004/index.html)と案内しています
- がんと診断されたとき働いていた 831 人の調査では、治療と仕事の両立で困難だったことの最多が「治療費が高い、治療費がいつ頃、いくらかかるか見通しが立たない」34.5% でした（[東京都 2014 年公表](https://www.gan-portal.metro.tokyo.lg.jp/uploads/01_260527_gaiyou.pdf)）

これらは困りごとの存在を示す数字で、アプリで減らせる割合ではありません。調査の範囲と限界は[調査メモ](docs/research/hospital-money-facts-20261105.md)に書きました。

**効果は確かめていません。** 当事者の評価は未実施です。確かめたのは、動くことと計算が合うことまでで、これで準備が進むかは分かっていません。

## 手元で動かす

Node.js 20.9 以降が必要です。

```sh
npm ci
cp .env.example .env.local   # ANTHROPIC_API_KEY を設定する
npm run dev                  # http://127.0.0.1:3000
```

- `ANTHROPIC_API_KEY`: アプリ専用のキー。シェル全体への export は要りません
- `ANTHROPIC_API_KEY_FILE`: 既存の鍵ファイルを使う場合の絶対パス。環境変数のキーがあれば、そちらを優先します
- `ANTHROPIC_MODEL`: 初期値は `claude-sonnet-5-5`
- `LIMIT_PER_CLIENT_PER_DAY`、`LIMIT_GLOBAL_PER_DAY`: 公開版の回数上限。省略すると 20 回と 150 回
- キーが無くても、架空の体験例で編集と持ち出しを試せます。API の失敗を見本の回答ですり替えることはしません

## Claude の使い方

### 製品の中

`claude-sonnet-5-5` に話の読み取りと言葉の部分を任せ、誤りが支払いに響く部分はプログラムに置きました。

| 担当       | すること                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| Claude     | 話から条件を読み取る。分からない値に仮の幅を置く。カードの文章を書く。質問は、答えで結果が変わるときに 1 つだけ |
| プログラム | 金額と日付の計算。引用と原文の照合。返答の金額と日付の照合。自分で直したカードの保護。持ち出す範囲の限定        |

- **構造化出力**: 返答とカードを Zod のスキーマで受け取ります（`lib/workspace.ts`）
- **道具（tool use）**: 高額療養費の上限、食事代、日付と営業日、支払いと入金の見通しの 4 つを道具にし、計算はそこだけで行います。範囲の外は計算せずに理由を返します
- **引用の完全一致**: 引用が利用者の発言に文字列として無ければ返答を捨てます。「残しておく言葉」は本文が引用と一致しなければ捨てます
- **金額の照合**: 返答に書かれた金額と日付を、道具の入出力・利用者の発言・出典つきの事実と照らし、見当たらなければ注意を出します

この分担にした理由は [ADR 0009](docs/adr/0009-conversational-hospital-cost-prototype.md) と [ADR 0011](docs/adr/0011-confirm-sakiyomi-and-include-money.md) にあります。試作を実 API で動かしたとき、Claude は丸めた額や自分で足した小計、道具を通していない日付を書きました（[ワークログ 11/6](docs/worklog/20261106.md)）。

### 開発の中

**Next.js アプリの初版のコードは Codex で実装しました。** Claude Code で行ったのは次の作業です。詳しくは[提出フォームの下書き](docs/submission/form.md#開発での-claude-code-とほかの道具)と[ワークログ](docs/worklog/README.md)にあります。

- 質問ツールでの仕様の聞き取り（16 問。当時の題材は子育て案）
- サブエージェントでの公式ページからの抽出。子育て案の制度データに 5 体、入院のお金の調査に 4 体。使う項目は一次資料の本文と突き合わせました
- お金の見通しの試作。計算、道具、返答の検査、テスト 130 件。利用上限で止まったあとの出典修正とコード確認は Codex で引き継ぎ、131 件になりました
- 試作の計算の本体への統合、利用上限の公開、作業の並列化、push の前に秘密情報を探す検査フック
- デモ動画の制作。曲の合成、本番 URL の録画、書き出し、語と金額の照合

Codex には、仕様への批判レビューと 11/5 の課題の比較も任せました。Managed Agents は計画しましたが、題材を変えたので作っていません。

## しないこと

- 診断、治療、入院日数、再発についての見通しや確率。体のことは主治医に聞くことだと伝えます
- 心理の助言
- 給付が出るか、いくら出るか、いつ入るかの判断。確かめる相手と聞き方までを出します
- 特定の保険や金融商品のすすめ
- 病院、保険会社、家族への連絡と申請の代行
- 人物の再現と、話していない思い出の生成

## 計算の範囲

協会けんぽ・70 歳未満・2026 年 8 月〜2027 年 7 月の診療分で、1 か月・1 つの医療機関の入院の保険診療分です。多数回該当、世帯合算、年間上限は入れていません。国民健康保険やほかの健康保険組合は、区分の決まり方や上乗せの給付が違うことがあります。食事代は 1 食 550 円を 1 日 3 食で数えた多めの見積もりです。営業日は土日・祝日・12/31〜1/3 を除きます（2026 年と 2027 年だけ）。民間保険の給付金と傷病手当金は計算しません。利用者が話した値か仮に置いた値を「確かめていない入金」として並べるだけです。

## データ

- 初期状態ではブラウザのメモリの中だけに置きます。「このブラウザに保存して、次回つづける」を選ぶと localStorage に残ります
- メニューの「かがみ」で撮った映像は、このタブのメモリにだけ置き、サーバーへ送りません。タブを閉じると消えます。残すときは端末に保存します。カメラとマイクは、応答のヘッダーでこのサイト自身にだけ許しています（`Permissions-Policy: camera=(self), microphone=(self), geolocation=()`、[ADR 0016](docs/adr/0016-kagami-recording-on-this-device-only.md)）
- 会話を送ると、その会話とメモをサーバー経由で Anthropic へ送ります。API キーはサーバーだけで読みます
- デモと公開データの人物と金額は、すべて架空です
