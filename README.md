# bwc-japan-2026

Anthropic と Cerebral Valley が主催するオンラインハッカソン **[Built with Claude: Japan 2026](https://cerebralvalley.ai/events/~/e/built-with-claude-japan2026)** に、個人で参加するためのリポジトリです。

> **題材は決まりました（[ADR 0002](docs/adr/0002-topic-gaps-left-by-existing-apps.md)）。** プロジェクト名とリポジトリ名は検討中です。

## 作るもの

既存の子育てアプリがカバーしていない「この時期にやること」を、家族ごとに出すものです。

### 誰の、どんな課題か

札幌で子育てをしている親の課題です。日々の記録はピヨログなど、園との連絡は園のアプリ、定期接種と健診は市の母子手帳アプリ（さっぽろ子育てアプリ＝母子モ）が持っています。それでも次のものは、どのアプリにもありません。

- 手続きとお金（児童手当・医療費助成・育児休業給付・会社に聞くこと）の時期
- 任意接種（インフルエンザ・新型コロナなど）の開始時期・回数・費用・助成の有無
- 預け先と、前もって済ませておく登録（例：病児保育は生後 5 か月から使えるが、予約システムへの登録と施設ごとの登録が先に要る）
- 「この時期だから、うちはこうする」という、家族ごとの次の一手

これらは役所・会社・市のウェブサイトに散らばっています。知らないと損をしたり、困った当日に間に合わなかったりします。近くに頼れる人がいない共働きの家庭ほど重くなります。どれくらい困っているかは、11/3〜4 の聞き取りで確かめて書き足します。

### どう解決するか

子の生年月日・住んでいる区・夫婦の働き方から、「今月うちがやること」を日付と出典つきで出します。

- 最初の入力は少なくし、済んだことは「インフル 1 回目を打った」のような一言で反映する
- 日付と、対象になるかどうかの判定はプログラムで計算し、Claude には作らせない
- 既存のアプリにあるもの（定期接種・日々の記録・園との連絡）は作らない。接種や受診をすべきかの判断、離乳食の助言、手続きの代行もしない

### テーマ

2「本来、誰にでも届くべきものを」です。専門知識と手続きの壁で、受けられるはずの支援を受けそびれている親に届けます。

### ハッカソンのあと、誰が使い続けるか

作者の家庭が、子どもが就学するまで使い続けます。札幌の子育て家庭であれば、保育園に通っているかどうかに関係なく使えます。
