# bwc-japan-2026

Anthropic と Cerebral Valley が主催するオンラインハッカソン **[Built with Claude: Japan 2026](https://cerebralvalley.ai/events/~/e/built-with-claude-japan2026)** に、個人で参加するためのリポジトリです。

> **題材は検討中です。** 決まったら「作るもの」とリポジトリ名を更新します。

## 作るもの

題材が決まったら記入します。書くことは次の 4 つです。

- 誰の、どんな課題か（その人が、どんな場面で、どれくらい困っているか）
- どう解決するか
- 選んだテーマ（#1「あなたにしかない深さを」か #2「本来、誰にでも届くべきものを」）
- ハッカソンのあと、誰が使い続けるか

## 大会について

| 項目     | 内容                                                                     |
| -------- | ------------------------------------------------------------------------ |
| 開発期間 | 2026-11-02（月）12:30 〜 11-08（日）20:00 JST                            |
