# さきよみ — 家族のための準備室

**使える制度を、支払日に間に合う準備へつなぐアプリです。**

入院が決まった人に、還付を待つ間のお金まで用意する負担が生じることがあります。さきよみは、普通の言葉から支払いの見通しを計算し、使える制度の確認と必要な手続きにつなげます。[Built with Claude: Japan 2026](https://cerebralvalley.ai/events/~/e/built-with-claude-japan2026) の提出作品で、テーマは 2「本来、誰にでも届くべきものを」（専門知識と手続きの壁）です。

| 誰の       | 入院が決まり、まとまった立替が家計の負担になる本人と家族。特に、窓口で医療費の上限を使えるかを、まだ確かめていない人                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| どんな課題 | 高額療養費には、あとで払い戻しを受ける方法と、窓口での支払いを上限までに抑える方法がある。窓口で上限を使わないと、上限を超えた分を還付まで立て替えることになり、支払日に手元のお金が足りなくなることがある |
| どう解くか | 入力欄は 1 つ。話から Claude が条件を読み取り、2 つの方法それぞれで支払日に要るお金をプログラムが計算する。差を見せ、病院に確かめる質問文と準備につなげる。答えを話すと計算し直す                        |

作者自身が入院の準備で、いくら要るのか、誰に何を頼むのかを整理しようとしたことが出発点です。

## 試す

**https://sakiyomi-bwc2026.vercel.app** （ログインも API キーも要りません）

デモ動画（11/7 の版。今回の改修の前の画面です。改修後の画面で録り直します、#37）: https://youtu.be/c-3mh5sisec

- 「まず、架空の体験例を見る」は回数の制限なく試せます。Claude を呼びません。帯の「続き: 病院の答えを話す」で、病院の答えを話したあとの更新まで見られます
- Claude との会話には上限があります。端末ごとに 1 日 20 回、全体で 1 日 150 回、短時間の連打は 1 時間 20 回までです。日本時間の 0 時に切り替わります。上限に達しても、入力とメモは画面に残ります（[ADR 0012](docs/adr/0012-open-production-with-usage-limits.md)）
- **実名や病名を書かず、架空の内容で試してください。** 送った内容はサーバーを経由して Anthropic へ送られます。アプリは本文を保存もログ出力もしません
- 回数はメモリの中で数えるので、厳密な上限ではありません。API の残高が尽きると会話は失敗し、体験例だけが動きます

試す文の例です。人物も金額も架空です。この順に話すと、下の「架空の例」の数字になります（月をまたぐときの内訳は Claude が仮に置くので、3 つ目は変わることがあります）。

> 12月14日に入院して、28日に退院する予定です。病院の見積もりだと、医療費は総額で80万円くらい。協会けんぽで、給料は月35万円くらいです。入院のために使えるお金は20万円で、生活費は別にしてあります。窓口でいくら払うことになるのか分かりません。

> 病院に聞いたら、マイナ保険証で窓口の上限は効くと言われました。

> 入院が1週間延びて、退院が1月4日になったら？

## 架空の例: 窓口で上限を使うかで、支払日に要るお金が変わる

条件: 2026 年 12 月 14〜28 日の入院（15 日）、協会けんぽ、70 歳未満、所得区分ウ（給料の額から仮に置く）、1 か月・1 つの医療機関、保険診療の総額 80 万円（病院の見積もり）、入院のために使える手元のお金 20 万円（生活費は別）。支払いは退院の日と仮に置きます。

|                                | 窓口で上限を使う         | 使わずに、あとで還付を受ける |
| ------------------------------ | ------------------------ | ---------------------------- |
| 入院費（保険診療分）           | 90,940 円（見積もり）    | 240,000 円（見積もり）       |
| 入院中の食事代                 | 24,750 円（仮定）        | 24,750 円（仮定）            |
| **支払日（12/28）に要るお金** | **115,690 円**           | **264,750 円**               |
| 手元の 200,000 円と比べて      | 84,310 円残る            | 64,750 円足りない            |

**差の 149,060 円が、窓口で上限を使えば避けられる一時立替です。** あとで還付を受ける場合、協会けんぽは払い戻しまで「診療月から3か月以上かかります」と案内しています（[よくある質問](https://www.kyoukaikenpo.or.jp/faq/benefit/004/index.html)、2026-11-07 確認）。

- 区分ウの 1 か月の上限は、85,800 円＋（総医療費 − 286,000 円）× 1%（2026 年 8 月〜2027 年 7 月の診療分。[協会けんぽ](https://www.kyoukaikenpo.or.jp/benefit/high_cost_medical_expenses/002/index.html)、2026-11-07 確認）。総額 80 万円なら 90,940 円です
- 窓口で上限までにするには、オンライン資格確認のある医療機関でマイナ保険証を使うか、限度額適用認定証を出します。認定証は医療費を払う前に申請が要ります（[協会けんぽ](https://www.kyoukaikenpo.or.jp/benefit/high_cost_medical_expenses/001/index.html)、2026-11-07 確認）
- 食事代は 1 日 3 食で数えた多めの見積もりで、仮定として扱います。差額ベッド代などは入っていません

**病院の答えで更新されます。** 2 つ目の文で病院の答えを話すと、上限を使う見通しに絞り、支払日に要るのは 115,690 円、手元から 84,310 円残る、要る額の幅は 149,060 円から 0 円に縮んだ、と計算し直します。入院費の額は見積もりの総額からの計算なので、確かさは「見積もり」のままです。3 つ目の文で 1 週間延びると、上限は月ごとに掛かるので、費用が 12 月に寄れば 127,240 円、半々に分かれれば 210,180 円（10,180 円足りない）に増えます。

表の金額はすべてアプリの計算の出力で、`tests/example.test.ts` がこの README の数字と照合しています。

## 一巡: 計算から、窓口での手続きまで

| 担い手   | すること                                                                                                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| アプリ   | **計算**（2 つの方法での支払日に要るお金、差、手元との差）、**質問文**（病院の会計にそのまま見せる文）、**準備の支援**（入院の受付でマイナ保険証を出す、使えないときの認定証）、**回答後の更新**（答えを話すと計算し直す） |
| 本人     | 窓口で確認し、手続きを進める。窓口での適用につながるところまでが一巡                                                                                                                  |

アプリは病院や保険者への連絡も申請もしません。給付が受けられるか、いくらか、いつかも断定しません。

## 社会の規模

- 協会けんぽの 2025 年度（令和 7 年度）の実績で、高額療養費のあとからの払い戻し（償還払い）は 104 万 2 千件、283 億円でした。窓口での適用（現物給付）は 460 万 5 千件、6,628 億円です（[令和 7 年度事業報告書 p.17](https://www.mhlw.go.jp/content/12400000/001748917.pdf#page=22)、2026-11-07 確認）。償還払いには外来や世帯の合算も含み、全額が避けられる立替ではありません
- 架空の例の差 149,060 円が 100 件なら、14,906,000 円（約 1,491 万円）の立替を避ける計算になります。**これは規模感で、達成予測ではありません。** 償還払いを件数でならすと 1 件あたり約 2.7 万円で、架空の例よりずっと小さい額です
- 過去 5 年に入院した 675 人のうち、窓口で上限までを払った人が 49.6%、いったん払って後から払い戻しを受けた人が 17.9% でした。自己負担は平均 18.7 万円です（[生命保険文化センター 2025 年度調査 p.60〜64](https://www.jili.or.jp/files/research/chousa/pdf/r7/2025honshi_all-.pdf)、2026-11-07 確認）
- がんと診断されたとき働いていた 831 人の調査では、治療と仕事の両立で困難だったことの最多が「治療費が高い、治療費がいつ頃、いくらかかるか見通しが立たない」34.5% でした（[東京都 2014 年公表](https://www.gan-portal.metro.tokyo.lg.jp/uploads/01_260527_gaiyou.pdf)、2026-11-07 確認）

これらは困りごとの存在と規模を示す数字で、アプリで減らせる割合ではありません。調査の範囲と限界は[調査メモ](docs/research/hospital-money-facts-20261105.md)に書きました。

## 家族の道具

本筋のあとに、家族に渡すための道具があります。

- **渡すもの**: 朝の支度などの引き継ぎ、窓口や身近な人への質問文と依頼文、本人が残したいと話した言葉（原文のまま）。自分で直した文章は、話を続けても上書きされません。選んだものだけを確認画面で読み、コピーかテキストで保存します。送るのは本人です
- **年表**（`/roadmap`）、**あそぶ**（`/play`、1〜2 歳向けで画面の文字は 0）、**かがみ**（撮影とプレビュー、#54 で作業中）: 1 つのメニューから移れます。移っても会話は消えません（[ADR 0015](docs/adr/0015-one-menu-for-sakiyomi-roadmap-and-play.md)）

## 手元で動かす

Node.js 20.9 以降が必要です。

```sh
npm ci
cp .env.example .env.local   # ANTHROPIC_API_KEY を設定する
npm run dev                  # http://127.0.0.1:3000
```

- `ANTHROPIC_API_KEY`: アプリ専用のキー。シェル全体への export は要りません
- `ANTHROPIC_API_KEY_FILE`: 既存の鍵ファイルを使う場合の絶対パス。環境変数のキーがあれば、そちらを優先します
- `ANTHROPIC_MODEL`: 初期値は `claude-sonnet-5-5`
- `LIMIT_PER_CLIENT_PER_DAY`、`LIMIT_GLOBAL_PER_DAY`: 公開版の回数上限。省略すると 20 回と 150 回
- キーが無くても、架空の体験例で編集と持ち出しを試せます。API の失敗を見本の回答ですり替えることはしません

## Claude の使い方

### 製品の中

`claude-sonnet-5-5` に話の読み取りと言葉の部分を任せ、誤りが支払いに響く部分はプログラムに置きました。

| 担当       | すること                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| Claude     | 話から条件を読み取る。分からない値に仮の幅を置く。カードの文章を書く。質問は、答えで結果が変わるときに 1 つだけ |
| プログラム | 金額と日付の計算。確かめることの順位。支払日の欄でどちらの筋書きが「窓口で上限を使う」かの見分け。引用と原文の照合。返答の金額と日付の照合。自分で直したカードの保護。持ち出す範囲の限定 |

- **構造化出力**: 返答とカードを Zod のスキーマで受け取ります（`lib/workspace.ts`）
- **道具（tool use）**: 高額療養費の上限、食事代、日付と営業日、支払いと入金の見通しの 4 つを道具にし、計算はそこだけで行います。範囲の外は計算せずに理由を返します
- **引用の完全一致**: 引用が利用者の発言に文字列として無ければ返答を捨てます。「残しておく言葉」は本文が引用と一致しなければ捨てます
- **金額の照合**: 返答に書かれた金額と日付を、道具の入出力・利用者の発言・出典つきの事実と照らし、見当たらなければ注意を出します
- **支払日の欄**: 「窓口で上限を使う」「使わずに、あとで還付」の 2 つの欄は、見通しの支払いの行が高額療養費の計算の額と一致するかで、プログラムが見分けます。Claude が付けた筋書きの名前では決めません。額は計算の出力を選んで並べるだけで、画面で新しい額を作りません（[ADR 0016](docs/adr/0016-payday-story-cap-at-desk-versus-refund.md)）

この分担にした理由は [ADR 0009](docs/adr/0009-conversational-hospital-cost-prototype.md)、[ADR 0011](docs/adr/0011-confirm-sakiyomi-and-include-money.md)、[ADR 0013](docs/adr/0013-decision-first-range-and-one-check.md) にあります。試作を実 API で動かしたとき、Claude は丸めた額や自分で足した小計、道具を通していない日付を書きました（[ワークログ 11/6](docs/worklog/20261106.md)）。

### 開発の中

**Next.js アプリの初版のコードは Codex で実装しました。** Claude Code で行ったのは次の作業です。詳しくは[提出フォームの下書き](docs/submission/form.md#開発での-claude-code-とほかの道具)と[ワークログ](docs/worklog/README.md)にあります。

- 質問ツールでの仕様の聞き取り（16 問。当時の題材は子育て案）
- サブエージェントでの公式ページからの抽出。子育て案の制度データに 5 体、入院のお金の調査に 4 体。使う項目は一次資料の本文と突き合わせました
- お金の見通しの試作。計算、道具、返答の検査、テスト 130 件。利用上限で止まったあとの出典修正とコード確認は Codex で引き継ぎ、131 件になりました
- 試作の計算の本体への統合、利用上限の公開、作業の並列化、push の前に秘密情報を探す検査フック
- デモ動画の制作。曲の合成、本番 URL の録画、書き出し、語と金額の照合

Codex には、仕様への批判レビューと 11/5 の課題の比較も任せました。Managed Agents は計画しましたが、題材を変えたので作っていません。

## しないこと

- 診断、治療、入院日数、再発についての見通しや確率。体のことは主治医に聞くことだと伝えます
- 心理の助言
- 給付が出るか、いくら出るか、いつ入るかの判断。確かめる相手と聞き方までを出します
- 特定の保険や金融商品のすすめ
- 病院、保険会社、家族への連絡と申請の代行
- 人物の再現と、話していない思い出の生成

## 計算の範囲

協会けんぽ・70 歳未満・2026 年 8 月〜2027 年 7 月の診療分で、1 か月・1 つの医療機関の入院の保険診療分です。多数回該当、世帯合算、年間上限は入れていません。国民健康保険やほかの健康保険組合は、区分の決まり方や上乗せの給付が違うことがあります。食事代は 1 食 550 円を 1 日 3 食で数えた多めの見積もりです。営業日は土日・祝日・12/31〜1/3 を除きます（2026 年と 2027 年だけ）。民間保険の給付金と傷病手当金は計算しません。利用者が話した値か仮に置いた値を「確かめていない入金」として並べるだけです。

## データ

- 初期状態ではブラウザのメモリの中だけに置きます。「このブラウザに保存して、次回つづける」を選ぶと localStorage に残ります
- 会話を送ると、その会話とメモをサーバー経由で Anthropic へ送ります。API キーはサーバーだけで読みます
- デモと公開データの人物と金額は、すべて架空です
