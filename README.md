# さきよみ — 入院のお金、支払日に間に合う準備

入院が決まった人に、還付を待つ間のお金まで用意する負担が生じることがあります。さきよみは、普通の言葉から支払いの見通しを計算し、使える制度の確認と必要な手続きにつなげます。

入院が決まった人が普通の言葉で話すと、支払日に要るお金を、窓口で上限が使える場合と使えない場合で並べ、まず確かめる 1 つを出す Web アプリです。家族や窓口に渡す文章も Claude が下書きします。[Built with Claude: Japan 2026](https://cerebralvalley.ai/events/~/e/built-with-claude-japan2026) の提出作品で、テーマは 2「本来、誰にでも届くべきものを」（専門知識と手続きの壁）です。

| 誰の       | 入院が決まった本人と、代わりに段取りを進める家族。特に、窓口で上限を使えるかをまだ確かめていない人                                                                                                                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| どんな課題 | 支払日に要るお金は、窓口で高額療養費の上限が使えるかで変わる。使えないと上限を超えた分をいったん立て替え、払い戻しは診療月から 3 か月以上あとになる。制度を知らないと、いくら用意するか、病院に何を先に確かめるかが決まらない                                                                                |
| どう解くか | 入力欄は 1 つ。話から Claude が条件を読み取り、金額と日付はプログラムが計算する。支払日に要るお金を上限が使える場合と使えない場合で並べ、幅を一番縮める確認を 1 つ出す。窓口の答えを話すと、答えの出た条件で計算し直して幅が縮む。家族と窓口に渡す文章は Claude が下書きし、自分で直して、渡すものだけ選べる |

軸は「制度利用の確認と手続きで、避けられる一時立替と資金不足を減らす」です。

## 試す

**https://sakiyomi-bwc2026.vercel.app** （ログインも API キーも要りません）

デモ動画: https://youtu.be/c-3mh5sisec （11/7 に録った版で、画面は今より前のものです）

- 「まず、架空の体験例を見る」は回数の制限なく試せます。Claude を呼びません
- Claude との会話には上限があります。接続元（回線）ごとに 1 日 20 回、全体で 1 日 150 回、短時間の連打は 1 時間 20 回までです。日本時間の 0 時に切り替わります。上限に達しても、入力とメモは画面に残ります（[ADR 0012](docs/adr/0012-open-production-with-usage-limits.md)）
- **実名や病名を書かず、架空の内容で試してください。** 送った内容はサーバーを経由して Anthropic へ送られます。アプリは本文を保存もログ出力もしません
- 回数はメモリの中で数えるので、厳密な上限ではありません。API の残高が尽きると会話は失敗し、体験例だけが動きます

試す文の例です。人物も金額も架空です。

> 12月14日に入院して、28日に退院する予定です。病院の見積もりだと、医療費は総額で80万円くらい。協会けんぽで、給料は月35万円くらいです。すぐ使えるお金は20万円。保険にも入っていて書類は青いファイルにあるけど、給付金がいつ入るのか分かりません。朝はいつも私が子どもの支度をしています。7時に起こして、着替えは寝室の白い棚、水筒はかばんの横、8時10分に家を出ます。夫に頼みたいけど、何をどう伝えればいいか。

続けて「病院に聞いたら、マイナ保険証で窓口の上限は使えると言われました。」と話すと、上限が使える筋書きだけが残り、要る額は 1 つになります。病院の答えで確かめたのは「窓口で上限が使えるか」だけで、医療費の総額 80 万円（病院の見積もり）と食事代は見積もりのままです。「入院が1週間延びて、退院が1月4日になったら？」と話すと、月をまたぐ分を月ごとに計算し直します。

## 何が返ってくるか

最初の画面は会話だけです。返答が届くと、メニューの「見通し」と「渡すもの」に結果が並びます。

| 場所     | 見るもの                                         | できるもの                                                                                                                                     | 未確認として残すもの                               |
| -------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 見通し   | 支払日に要るお金                                 | 筋書きごとの要る額、いつ、手元のお金との差、確かさ。筋書きが 2 つ以上なら、その差と、払い戻しは診療月から 3 か月以上あとという注意（出典つき） | 見積もりと実際の請求の差、窓口の答えそのもの       |
| 見通し   | まず確かめる 1 つ                                | いまの幅、確かめると残る幅、答えごとの要る額、聞く相手と質問文のコピー                                                                         | 仮定のまま残る値、話されていない費用               |
| 見通し   | 計算の記録                                       | お金の出入り、高額療養費の上限、食事代、日付と営業日、出典と確認日                                                                             | —                                                  |
| 渡すもの | 暮らしの引き継ぎ、確かめる・頼む、残しておく言葉 | 朝の支度などの手順。窓口や身近な人にそのまま見せられる質問文と依頼文。本人が残したいと話した言葉の原文                                         | 担当する人の了承、給付の可否と額、相手の回答と同意 |

自分で直したカード、「準備できた」にしたカード、渡すと選んだカードは、話を続けても上書きされません。「渡すものに含める」を選んだものだけを確認画面で読み、コピーかテキストで保存します。会話の全文は入りません。送るのは本人です。

メニューは 1 つで、主役は「話す・見通し・渡すもの」です。区切りのあとに「年表・あそぶ・かがみ」を小さく並べます。年表は札幌の子育て年表、あそぶは 1〜2 歳向けの画面の文字が 0 のあそび、かがみはこの端末で撮って見るだけの撮影とプレビューです（映像はサーバーへ送らず、ブラウザの保存領域にも書きません。残すときは本人が端末に保存します）。3 つとも入院のお金の計算とデータを共有せず、Claude も呼ばない補助です（[ADR 0015](docs/adr/0015-one-menu-for-sakiyomi-roadmap-and-play.md)、[ADR 0017](docs/adr/0017-kagami-recording-on-this-device-only.md)）。あそぶではメニューを出さず、隅の家の絵を約 1.5 秒押し続けると戻ります。

上の例をプログラムで計算すると、次のようになります。条件は架空で、協会けんぽ・区分ウ・医療費の総額 80 万円・手元 20 万円です。前提は 70 歳未満、1 か月・1 つの医療機関で（月をまたぐ行は月ごとに分けて計算）、手元の 20 万円は入院に使える額として置いた仮定です。区分ウも、話してもらった給料（月 35 万円）から仮に置いた区分で、加入している健康保険に確かめる値です。

| 条件                                                                                  | 要る額     | 手元との差        |
| ------------------------------------------------------------------------------------- | ---------- | ----------------- |
| 12 月 14 日〜28 日の 15 日間。窓口で上限が使える                                      | 115,690 円 | 84,310 円残る     |
| 同じ 15 日間。上限が使えず、いったん 3 割を払う                                       | 264,750 円 | 64,750 円足りない |
| 1 週間延びて 1 月 4 日に退院（22 日間）。費用が 12 月に寄る（80 万・0）、上限が使える | 127,240 円 | 72,760 円残る     |
| 同じ 22 日間。費用が半々（40 万・40 万）、上限が使える                                | 210,180 円 | 10,180 円足りない |
| 同じ 22 日間。上限が使えず、いったん 3 割を払う                                       | 276,300 円 | 76,300 円足りない |

1 回目の返答は上の 2 行を並べ、差の 149,060 円は、この仮定で上限が使えなかったときにあとから払い戻される見込みの額で、支給されるか、いつ入るかは加入している健康保険に確かめることだと伝え、まず確かめる 1 つを「窓口で上限が使えるか」（聞く相手は病院の会計）と出します。窓口で上限が使えれば、この 149,060 円を払い戻しまで立て替えずに済む見込みです（この仮定での見込みで、言い切れるものではありません）。内訳は、保険診療分 90,940 円（区分ウ: 85,800 円 ＋（800,000 円 − 286,000 円）× 1%）と食事代 24,750 円（550 円 × 3 食 × 15 日）です。区分ウの式は[全国健康保険協会（高額療養費の自己負担限度額の表）](https://www.kyoukaikenpo.or.jp/benefit/high_cost_medical_expenses/002/index.html)（確認 2026-11-06）、1 食 550 円は[全国健康保険協会（入院時食事療養費）](https://www.kyoukaikenpo.or.jp/benefit/mynumber_insurance_card/002/index.html)（確認 2026-11-06）によります。高額療養費の上限は月ごとに掛かるので、総額が同じと仮定しても月をまたぐと要る額が増えます。月の内訳は Claude が仮に置くので、実際の返答が表と同じになるとは限りません。表の値は `tests/readme-numbers.test.ts` で計算関数と照合しています。

## なぜこの課題か

公開の調査と制度の案内から分かっているのは次のことです。数字は規模感で、達成予測ではありません。

- 退院は 1 か月に 138.8 万件（2023 年 9 月、病院と一般診療所の推計）。病院の退院の 68.4% が在院 14 日以内、15.5% が 15〜30 日で、月をまたぐ入院が珍しくない規模です（[厚生労働省 令和 5 年患者調査の概況 p.14〜15](https://www.mhlw.go.jp/toukei/saikin/hw/kanja/23/dl/kanjya.pdf)、確認 2026-11-07）
- 過去 5 年に入院した人の自己負担は平均 18.7 万円。直近の入院で高額療養費を使った人は、過去 5 年に入院した 675 人の 67.6% で、内訳は窓口で上限までを払った人が 49.6%、いったん払って後から払い戻しを受けた人が 17.9% でした。49.6% と 17.9% も 675 人全体に占める割合です（[生命保険文化センター 2025 年度調査 p.60〜64。高額療養費の利用は図表Ⅱ－9](https://www.jili.or.jp/files/research/chousa/pdf/r7/2025honshi_all-.pdf)、確認 2026-11-07）。後払いの場合、協会けんぽは払い戻しまで[診療月から 3 か月以上](https://www.kyoukaikenpo.or.jp/faq/benefit/004/index.html)と案内しています（確認 2026-11-07）
- 協会けんぽでは、窓口でマイナ保険証を出して「限度額情報の表示」に同意すれば、その医療機関での 1 か月（1 日から月末まで）の保険診療分の支払いが、最初から上限までになります。上限は医療機関ごとで、入院と外来も別に扱います。差額ベッド代などの保険外の負担と入院中の食事代は対象外で、別に払います。同じ月に入院と外来などを受けると、あとから申請が要ることがあります。オンライン資格確認を入れていない医療機関や、協会けんぽにマイナンバーが登録されていない場合は、限度額適用認定証を資格確認書と一緒に窓口に出します（[協会けんぽ 高額な診療が見込まれるとき](https://www.kyoukaikenpo.or.jp/application_form/benefit/004/index.html)、確認 2026-11-07）
- それでも後払いは残っています。協会けんぽの 2025 年度（2025 年 4 月〜2026 年 3 月）の高額療養費は、窓口で上限を掛けた現物給付が 460 万 5 千件、後から払い戻す償還払いが 104 万 2 千件・283 億円でした。件数は人数ではなく（1 人が 2 か月受ければ 2 件）、入院以外と高額介護合算も含みます（[協会けんぽ 令和 7 年度事業報告書 p.17〜18 図表 3-14](https://www.kyoukaikenpo.or.jp/assets/r7-3_BusiRepo.pdf)、確認 2026-11-07）
- がんと診断されたとき働いていた 831 人の調査では、治療と仕事の両立で困難だったことの最多が「治療費が高い、治療費がいつ頃、いくらかかるか見通しが立たない」34.5% でした（[東京都 2014 年公表](https://www.gan-portal.metro.tokyo.lg.jp/uploads/01_260527_gaiyou.pdf)、確認 2026-11-07）
- 高額療養費は 2026 年 8 月に月額の上限が見直されて年間上限が設けられ、2027 年 8 月に所得区分が細かくなります（[厚生労働省 高額療養費制度のページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryouhoken/juuyou/kougakuiryou/index.html)、確認 2026-11-07）。ネット上の解説と計算ツールが古くなる時期で、出典と確認日つきの表を保ち続ける計算器に継続の価値があります

これらは困りごとの存在と規模を示す数字で、アプリで減らせる割合ではありません。調査の範囲と限界は[調査メモ](docs/research/hospital-money-facts-20261105.md)に書きました。

**効果は確かめていません。** 当事者の評価は 0 件です。確かめたのは、動くことと計算が合うことまでで、これで準備が進むかは分かっていません。

### 一巡と、測るもの

| 担い手 | すること                                                                                             |
| ------ | ---------------------------------------------------------------------------------------------------- |
| アプリ | 支払日に要るお金の計算、窓口に聞く質問文、家族に渡すものなど準備の支援、答えを話したあとの計算し直し |
| 本人   | 窓口で確かめ、必要な手続きを進める。窓口で上限が使えるようになるまでが一巡                           |

アプリは連絡も申請もしません。測るものは、新たに窓口で上限が使えるようになった件数、避けられた一時立替の額、支払日の不足が解消した件数の 3 つです。どれもまだ測っていません。アプリは利用の記録を集めないので、測るなら、同意を得た聞き取りになります。

規模の目安です。規模感で、達成予測ではありません。架空の例の差 149,060 円が 100 件なら 14,906,000 円（約 1,491 万円）です。一方、上の協会けんぽの償還払い 283 億円を 104 万 2 千件でならすと 1 件あたり約 2.7 万円で、架空の例よりずっと小さくなります。

## 手元で動かす

Node.js 20.9 以降が必要です。テストを回すなら 24 を使います（CI と本番と同じ。22 では会話の時間切れのテストが打ち切られます）。

```sh
npm ci
cp .env.example .env.local   # ANTHROPIC_API_KEY を設定する
npm run dev                  # http://127.0.0.1:3000
```

- `ANTHROPIC_API_KEY`: アプリ専用のキー。シェル全体への export は要りません
- `ANTHROPIC_API_KEY_FILE`: 既存の鍵ファイルを使う場合の絶対パス。環境変数のキーがあれば、そちらを優先します
- `ANTHROPIC_MODEL`: 初期値は `claude-sonnet-5-5`
- `LIMIT_PER_CLIENT_PER_DAY`、`LIMIT_GLOBAL_PER_DAY`: 公開版の回数上限。省略すると 20 回と 150 回
- キーが無くても、架空の体験例で編集と持ち出しを試せます。API の失敗を見本の回答ですり替えることはしません

## Claude の使い方

### 製品の中

`claude-sonnet-5-5` に話の読み取りと言葉の部分を任せ、誤りが支払いに響く部分はプログラムに置きました。

| 担当       | すること                                                                                                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude     | 話から条件を読み取る。分からない値に仮の幅を置く。プログラムが選んだ不明点を、誰に・何を・どう聞くかの質問文にする。カードの文章を書く。利用者への質問は、答えで結果が変わるときに 1 つだけ |
| プログラム | 金額と日付の計算。不明点の列挙と順位。引用と原文の照合。返答の金額と日付の照合。自分で直したカードの保護。持ち出す範囲の限定                                                                |

- **道具（tool use）**: 高額療養費の上限、食事代、日付と営業日、支払いと入金の見通しの 4 つを道具にし（`lib/money/tools.ts`、strict）、計算はそこだけで行います。範囲の外は計算せずに理由を返します。「まず確かめる 1 つ」の順位は、見通しの結果に `what_to_confirm` として同梱し、プログラムが計算します（`lib/money/confirm.ts`）。Claude に順位を決めさせません
- **構造化出力**: 返答とカードを Zod のスキーマで受け取ります（`lib/workspace.ts`）
- **引用の完全一致**: 引用が利用者の発言に文字列として無ければ、そのカードを出さずに注意を出します（計算の表のカードは捨てず、根拠を最後の発言に置き換えます）。「残しておく言葉」は本文が引用と一致しなければ出しません
- **金額と日付の照合**: 返答に書かれた金額と日付を、道具の入出力・利用者の発言・出典つきの事実と照らします。見当たらない金額と日付は返答の本文で「（照合できない金額）」のように伏せ、注意を出します。照らせない値を含む文章のカードは出さず、お金のカードは表を残してその部分だけ伏せます（`lib/money/guard.ts`、`lib/chat.ts`）。縮まない確認を「縮みます」と書いた文も指摘します
- **呼んだ計算の表示**: 返答の下に「この返答で呼んだ計算」を出します。Claude が何を計算に回したかを読めます

この分担にした理由は [ADR 0009](docs/adr/0009-conversational-hospital-cost-prototype.md)、[ADR 0011](docs/adr/0011-confirm-sakiyomi-and-include-money.md)、[ADR 0013](docs/adr/0013-decision-first-range-and-one-check.md) にあります。試作を実 API で動かしたとき、Claude は丸めた額や自分で足した小計、道具を通していない日付を書きました（[ワークログ 11/6](docs/worklog/20261106.md)）。本体でも、縮まない確認を「縮みます」と書いた返答があり、検査を足しました（[ワークログ 11/7](docs/worklog/20261107.md)）。

- **Skill** `.claude/skills/rules-freshness/`: 制度表 `lib/money/rules.ts` の鮮度点検の手順。出典の 5 区分の上限、食事代、祝日を表と突き合わせます
- **サブエージェント** `.claude/agents/rules-auditor.md`: 出典のページと `rules.ts` を突き合わせ、差分だけ Issue にします。編集の道具を持ちません
- **フック** 3 つ（`.claude/hooks/`）: `pre-push-check.sh` は push の前に公開前の検査を走らせ、`rules-freshness-check.sh` は `rules.ts` の値を変えたのに確認日を更新していない編集のあとで検査し、通らなければ Claude に差し戻し（編集は取り消しません）、`rules-auditor-guard.sh` は点検役の道具を絞ります
- **CI**（`.github/workflows/ci.yml`）: push と PR のたびに Node 24 で typecheck・test・check:public を回します

Codex には、仕様への批判レビューと 11/5 の課題の比較も任せました。Managed Agents は計画しましたが、題材を変えたので作っていません。

## しないこと

- 診断、治療、入院日数、再発についての見通しや確率。体のことは主治医に聞くことだと伝えます
- 心理の助言
- 給付が出るか、いくら出るか、いつ入るかの判断。確かめる相手と聞き方までを出します
- 特定の保険や金融商品のすすめ
- 病院、保険会社、家族への連絡と申請の代行
- 人物の再現と、話していない思い出の生成
- 確認の順位は額の幅の縮み方だけで決め、医学的な重要度ではありません

## 計算の範囲

協会けんぽ・70 歳未満・2026 年 8 月〜2027 年 7 月の診療分で、1 か月・1 つの医療機関の入院の保険診療分です。多数回該当、世帯合算、年間上限は入れていません。国民健康保険やほかの健康保険組合は、区分の決まり方や上乗せの給付が違うことがあります。食事代は 1 食 550 円を 1 日 3 食で数えた多めの見積もりです。営業日は土日・祝日・12/31〜1/3 を除きます（2026 年と 2027 年だけ）。民間保険の給付金と傷病手当金は計算しません。利用者が話した値か仮に置いた値を「確かめていない入金」として並べるだけです。

## データ

- 初期状態ではブラウザのメモリの中だけに置きます。「このブラウザに保存して、次回つづける」を選ぶと localStorage に残ります
- メニューの「年表」の設定とチェックも、初期状態ではこのタブのメモリの中だけに置きます。年表の設定の「このブラウザに保存して、次回つづける」を選んだときだけ localStorage に残し、選ぶのをやめると消します
- メニューの「かがみ」で撮った映像は、このタブのメモリにだけ置き、サーバーへ送りません。タブを閉じると消えます。残すときは端末に保存します。カメラとマイクは、応答のヘッダーでこのサイト自身にだけ許しています（`Permissions-Policy: camera=(self), microphone=(self), geolocation=()`、[ADR 0017](docs/adr/0017-kagami-recording-on-this-device-only.md)）
- 会話を送ると、その会話とメモをサーバー経由で Anthropic へ送ります。API キーはサーバーだけで読みます
- デモと公開データの人物と金額は、すべて架空です
