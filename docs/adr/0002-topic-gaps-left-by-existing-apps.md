# 0002. 題材：既存の子育てアプリがカバーしていない「この時期にやること」を作る

- 状態: 置き換え（0011。題材としての役割を置き換えた。見直す条件は 0004 で置き換えていた）
- 日付: 2026-11-02
- 関連: #1

## 背景

- 作者の家庭は札幌に住む共働きで、近くに頼れる親族がいない。子育ての困りごとを書き出すと、手続き・給付金・予防接種・預け先・「この時期に何をするか」の段取りが多かった
- 札幌の子育て家庭は、すでに次の 3 種類のアプリを使っている

| 種類                   | 例                                                | 持っているもの                                                                |
| ---------------------- | ------------------------------------------------- | ----------------------------------------------------------------------------- |
| 日々の記録             | ピヨログ                                          | 授乳・睡眠・おむつなど                                                        |
| 園との連絡             | ルクミー、コドモン                                | 連絡帳・お知らせ                                                              |
| 自治体の母子手帳アプリ | さっぽろ子育てアプリ（母子モ。2026-10-26 に刷新） | 定期接種のスケジュールと記録、健診・成長記録、市のお知らせ、家族共有、12 言語 |

- 出典は [札幌市 2026-10-07 市長会見資料](https://www.city.sapporo.jp/city/mayor/interview/text/2026/documents/20261007_kosodateapp.pdf)。月齢ごとの育児情報（きずなメール）は、10/26 から札幌市公式 LINE で届く（同資料）
- それでも、次のものはどのアプリにも無い。母子モの [App Store の説明](https://apps.apple.com/jp/app/id1106750564) と市の資料で確かめた。札幌版の実際の画面は未確認
  - 手続きとお金（児童手当・医療費助成・育児休業給付・会社に聞くこと）の時期
  - 任意接種（インフルエンザ・新型コロナなど）の開始時期・回数・費用・助成の有無
  - 預け先と、前もって済ませておく登録
  - 「この時期だから、うちはこうする」という、家族ごとの次の一手
- 預け先の登録は、困った当日に始めても間に合わない
  - 病児保育は生後 5 か月から使えるが、予約システム「テオテ」のアカウント作成と施設ごとの子どもの登録が要る。予約は前日 12 時からで、医師の利用連絡書も要る（[札幌市](https://kosodate.city.sapporo.jp/nenrei/mosugu/azukeru/1140.html)）
  - 子サポ（さっぽろ子育てサポートセンター）は、提供会員との顔合わせが済むまで頼めない（[札幌市](https://kosodate.city.sapporo.jp/nenrei/mosugu/azukeru/1138.html)）
- 既存のアプリは入力の手間が大きい。作者も、母子モに接種歴を入れる段階で手が止まった

## 決めたこと

- 既存の 3 種類のアプリがカバーしていない領域だけを作る。子の時期と家族の状況から「今月うちがやること」を、日付と出典つきで出す
- 使うのは親だけ。保育園に通っていない家庭も使える。保育園や自治体には、新しい作業を求めない
- テーマは 2「本来、誰にでも届くべきものを」（専門知識・手続きの壁）にする
- 作り方の原則
  - 最初の入力は、子の生年月日・住んでいる区・夫婦の働き方くらいに抑える
  - 済んだことは「インフル 1 回目を打った」のような一言で反映する
  - 日付と、対象になるかどうかの判定はプログラムで計算する。Claude には作らせない
  - 項目にはすべて出典 URL と確認日を付ける

作らないものは次のとおり。

| 作らないもの                                 | 理由                                                                 |
| -------------------------------------------- | -------------------------------------------------------------------- |
| 定期接種のスケジュールと記録、健診・成長記録 | 母子モにある                                                         |
| 授乳・睡眠などの日々の記録                   | ピヨログなどにある                                                   |
| 保育園との連絡                               | 園のアプリにある。保育園に通っていない家庭もいる                     |
| 接種や受診をすべきかの判断                   | 医療の助言にあたる                                                   |
| 離乳食のメニューや量                         | 栄養の助言にあたる                                                   |
| 会社や役所の手続きの代行                     | 社労士・行政書士の業務にあたる。「いつ、誰に、何を聞くか」までにする |
| 母子手帳や書類の写真の読み取り               | 画像解析にあたる。入力の手間は一言の入力で減らす                     |

## 検討したほかの案

比較は外部のモデル（Codex）にも批判させ、指摘は札幌市と北海道の公式ページで確かめた。

| 案                                                                     | 採らなかった理由                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 予防接種まで含めた時期の段取り帳                                       | 定期接種のスケジュールと家族共有は母子モにある                                                                                                                                                                                                                                                                                                            |
| 子連れ外出の「行けるか」チェック（性別を問わず使えるおむつ台・授乳室） | 北海道の「赤ちゃんのほっとステーション」に施設の登録と検索があり、性別を問わず使えるかも載っている（[例](https://hagukumu-hokkaido.com/custom_hot_station/custom_hot_station-26508/)）                                                                                                                                                                    |
| 頼れる人がいない家庭の預け先の段取り（当日の穴埋め）                   | 制度を案内しても、預け先の空きは増えない。緊サポはその都度提供会員を探し、希望どおり使えないことがある（[札幌市](https://kosodate.city.sapporo.jp/mokuteki/azukeru/syogakumae/1131.html)）。制度の質問には市の AI チャットボットがある（[札幌市](https://kosodate.city.sapporo.jp/mokuteki/others/11924.html)）。事前登録の段取りだけ、この題材に取り込む |
| 送り迎えの引き継ぎ（親から親、親から保育士）                           | 園との連絡は園のアプリで済んでいる。保育園に通っていない家庭は使えない。保育士は新しいツールを増やせない                                                                                                                                                                                                                                                  |
| 出産から 1 歳までの届出と入金の予定表（期間前の構想）                  | 届出だけでは差が出ないとして見送っていた。今回は任意接種・預け先・家族ごとの次の一手を足し、就学前まで広げる                                                                                                                                                                                                                                              |

## 結果

- 3 つのアプリを入れても残る困りごとを、一か所にまとめられる。デモで「既存のアプリと何が違うか」を言い切れる
- 引き受けること: 制度の正確さ。全項目に出典と確認日を付け、出典が変わったら人が確かめて直す
- 引き受けること: 「届出の予定表」と同じナビ型に見える恐れ。家族の状況から次の一手を出すところと、入力の少なさで差を付ける
- 見直す条件: 11/3〜4 に、保育園に通う家庭・通わない家庭の親と保育士に「最近 1 か月で、知らずに損をした・慌てた手続き・接種・預け先」を聞く。ほとんど出てこなければ、題材を見直す
- プロジェクト名とリポジトリ名は #2 で決める
