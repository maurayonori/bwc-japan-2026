# 0003. 初版から「項目への質問」と「発達の目安」を外す

- 状態: 採用
- 日付: 2026-11-04
- 関連: [spec.md](../spec.md)、[ADR 0002](0002-topic-gaps-left-by-existing-apps.md)

## 背景

- 11/3〜4 の聞き取りで、Claude の役割に「項目の質問への答え（出典の範囲で答える）」を、出す領域に「発達に合わせたできるようになること」を入れた
- 仕様の初版を外部レビュー（Codex）にかけたところ、次の指摘があった
  - 質問に答えるには出典の本文を持つ必要があるが、制度データに本文の欄が無く、実行時に公式ページも読まない。本文を持たせると「文書を検索して答えるだけ」の基本 RAG に見える。基本 RAG は大会の禁止例
  - 発達の目安（離乳食の開始時期など）は栄養の助言との境界が曖昧。栄養の助言は大会の禁止例
  - 任意接種を家庭ごとに「今やること」として出すと、接種の推奨に見える恐れがある
- 削る順を「発達 → 預け先 → 接種 → 手続き」の領域ごとにすると、ADR 0002 で差別化に挙げた「預け先の事前登録」が最初に消え、見送った「届出予定表」の案に近づく

## 決めたこと

1. **項目への質問は初版から外す。** 項目には Claude の短い説明文と、窓口・出典へのリンクだけを置く。Claude の役割は、一言の解釈・次の一手の説明文・データの鮮度点検の 3 つになる
2. **発達の目安は初版に入れない。** 入れるなら大会のあとに、時期の目安だけに限る
3. **任意接種は「この月齢から受けられる」「費用・助成・窓口」として出し、「打つべき」「おすすめ」とは書かない。** Claude の説明文にも同じ決まりを置く
4. **削るときは領域ごとではなく件数で削る。** 病児保育の登録 1 件は必ず残す

## 検討したほかの案

| 案                                           | 採らなかった理由                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------------ |
| 制度データに出典の抜粋を持たせて質問に答える | データ作りが増え、検索して答えるだけに見える恐れが残る。6 日では確かめきれない |
| 発達の目安を時期だけに絞って残す             | 時期だけでも「この月齢で離乳食」は助言に読まれうる。差別化にもならない         |
| 削る順を元のまま領域ごとにする               | 預け先が最初に消え、題材の差別化が薄れる                                       |

## 結果

- 作るものが減り、11/6 に通しで動く見込みが上がる
- 「項目について聞ける」便利さは失う。窓口へのリンクで補う
- 2 人対応と Managed Agents（11/7）は、レビューでは後回しを勧められたが、作者の判断で元のまま進める。計画より先行することを狙い、間に合わなければそのとき削る
