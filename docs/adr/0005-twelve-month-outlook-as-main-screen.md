# 0005. 主画面を TODO の一覧ではなく「これからの 12 か月の見通し」にする

- 状態: 採用
- 日付: 2026-11-04
- 関連: [spec.md](../spec.md)、[ADR 0003](0003-first-version-scope-cuts.md)、[ADR 0004](0004-evidence-from-public-surveys-and-registration-first.md)、#10

## 背景

- ADR 0004 で第一声を「困った日には間に合わない登録を、先に済ませる」にしたが、画面は spec 第 3 版まで「今やること」の一覧（TODO）だった。競合の Agent i も TODO の形
- 作者の指摘: 「手続きとお金の一般的な TODO より、どれくらいの確からしさで何が起きるかが分かれば、制度・任意接種・お金の用意ができる。忙しい生活の中ではイベントをざっと忘れる」
- 使える公的な数字を確かめた
  - 1 歳児の通園児は年およそ 12 日、保育園に通えない（先行研究への言及。[東京都 病児保育部会 議事録 2026-09-08](https://www.fukushi.metro.tokyo.lg.jp/documents/d/fukushi/02gijiroku-pdf)）
  - 子の病気で母が休む日数は 6〜10 日が最多、父は 2 日と 5 日が最多（同議事録、6,181 人）
  - 流行期: インフルエンザは冬（1 月がピーク）、RS ウイルスは夏の終わりから、手足口病は初夏〜夏。定点把握の感染症は 1 歳台の報告が最多（[熊本県](https://www.pref.kumamoto.jp/uploaded/attachment/111659.pdf)・[大阪市](https://www.city.osaka.lg.jp/kenko/cmsfiles/contents/0000222/222868/kansen34_23.pdf)の発生動向。全国値は JIHS で取る）
  - 児童手当は 3 歳未満 15,000 円/月、偶数月に年 6 回（[宮城県](https://www.pref.miyagi.jp/soshiki/kosodate/child-allowance.html)・[鹿児島市](https://www.city.kagoshima.lg.jp/faq-kosodate-kyoiku/kodomofuku/q31.html)）
- 病気や合併症の確率を任意接種の隣に置くと、接種の推奨に見える。ADR 0003 で避けた形で、大会の禁止例「医療の助言」に近づく

## 決めたこと

1. **主画面は「これからの 12 か月の見通し」。** 月ごとに 3 レーン: 起きうること／先に済ませること／お金。「今やること」の一覧は「先に済ませること」のレーンになる。項目を開く・一言で済み・.ics の書き出しは変えない
2. **起きうることは生活のイベントだけ。** 病欠日数の目安・親が休む日数・流行期・給付が入る月・期限。公的機関か査読論文の出典が取れた数字だけを出し、出典と確認日を付ける。病気や合併症の確率、ワクチンの効果は出さない。任意接種は「受けられる・費用・助成」のまま
3. **お金は公的な定額だけ。** 児童手当（偶数月に年 6 回）・助成・任意接種の費用の目安。保育料は「所得で変わる」と出すだけ。収入は入力しない
4. **見通しを動かすレバーは、入園予定月と第 2 子の予定（出産予定日）。** どちらも任意の入力。入園予定月で、病児保育の登録の期日・病欠の目安・給付の終わりが連動して変わる。第 2 子の予定日を入れると 2 人目のレーンが増え、児童手当と第 2 子以降の保育料無償（札幌市）が反映される
5. **データを 2 つ足す。** 「起きうること」の `events.yaml` と、期日の決まり方の 6 種類目 `before_milestone`（入園予定月の初日・復職予定日の N 日前）。形は [data/README.md](../../data/README.md)

## 検討したほかの案

| 案                                          | 採らなかった理由                                                                                     |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| TODO の一覧を主画面にし、見通しはタブで足す | Agent i と同じ形が最初に見える。差が伝わらない                                                       |
| 病気や合併症の確率も任意接種の隣に出す      | 推奨に見える。ADR 0003 を覆し、大会の禁止例に近づく                                                  |
| 月収を入れると育休給付も試算する            | 入力が増える。半日の追加。定額だけでも見通しは成り立つ                                               |
| 第 2 子の予定は入れない                     | 作者が「入れる」を選んだ。兄弟で通園できない日数が増えることを見せる価値がある。重ければ 11/6 に削る |

## 結果

- 作るものが増える: 見通しの画面・`events.yaml`・レバー 2 つ・`before_milestone` の計算
- 11/6 に通しで動かなければ、第 2 子 → 起きうることの数字 → .ics の順で削る。病児保育の登録は残す
- デモは「レバーを動かすと見通しが変わる」を見せる。入園予定月を 2027 年 4 月にすると、病児保育の登録と病欠の目安が 3〜4 月に現れる
- 「起きうること」の数字は人が出典を確かめてから入れる。出典が取れなかった数字は出さない
