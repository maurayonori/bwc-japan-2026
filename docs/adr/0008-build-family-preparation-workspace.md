# ADR 0008：会話から家族の準備を進め、選んだ文章を持ち出せる初版

- 日付：2026-11-06
- 状態：置き換え（0011。置き換えたのは「金額計算を含めない」だけで、ほかは有効）
- 関連：ADR 0007、課題検証 #22

## 背景

作者から、検討を続けるだけでなく、時間の限られた状況でも役に立つものを今日触れる状態にする依頼を受けた。入院費用の確認は準備の一部であり、それだけで家族の生活や引き継ぎの課題全体を解いたとは扱わない。固定フォーム・定型の質問票は採らない。

個人的な聞き取りの詳細は公開資料に転載しない。デモは新しく作った架空の場面を用いる。

## 判断

既に選定していたNext.jsとTypeScriptで、自然な会話を入口にする。Claudeが会話から実務の文章と次の行動を作り、利用者が確かめて持ち出す。

- 暮らしの引き継ぎ：朝の支度など、本人が担っていることを渡せる文章にする。
- 確かめる・頼む：保険会社や支援を頼む相手に、そのまま読める質問・依頼文にする。回答や相手の同意は未確認として残す。
- 残しておく言葉：本人が残したいと話した原文を引用する。体験や語りを創作しない。

3種類をすべて埋める必要はなく、利用者が話した範囲から作る。返答のための問いは必要なときに最大1つとする。

会話だけで終わらせず、編集・準備完了・共有対象の選択・コピー・テキスト保存を実装する。編集・完了・選択済みの文章は自動上書きしない。引用の完全一致、API入力のサイズ、保存データの形式はプログラムで検査する。

## 接続と保存

AI SDKの構造化出力とAnthropicプロバイダーを使用。実装時の公式一覧で確認したClaude Sonnet 5.5を指定し、既存のハッカソン用キーをサーバーからファイル参照する。キーの値をGitやクライアントへ渡さず、シェル全体にもexportしない。

ブラウザ内の保存は利用者が選ぶ。会話時には画面の会話・メモをAnthropicへ送信し、アプリのサーバーには本文を保存・ログ出力しない。メモを持ち出す前に実際の文章を表示し、選んでいないものと会話全文を含めない。

ローカルで触ることを今回の完了範囲とする。一般公開時の認証・利用量制限・共有方法は別途必要。通信失敗や未接続を、固定の回答で隠さない。架空の体験例は明示して用意する。

## 今回含めないもの

医療・心理の助言、死亡確率の判定、制度や保障の断定、外部への送信・代理申請、人物の再現、金額計算。以前の計算試作は内部確認用に残す。提出物の送信・公開デプロイ・動画作成はこの初版の実装とは別の作業である。

## 検証すること

自然な文章から役に立つメモができるか、訂正が保持されるか、渡したくない内容を持ち出しから外せるか、必要な確認や相談が実際に進むか。実機での生成・編集・保存・復元・持ち出しを先に確認する。不安の解消や継続利用、支払意思は未検証であり、実装完了から推定しない。
