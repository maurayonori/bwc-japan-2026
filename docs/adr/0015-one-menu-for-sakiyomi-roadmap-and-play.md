# 0015. 1 つのメニューから会話・年表・あそぶへ移れるようにし、移るあいだの会話はタブのメモリにだけ置く

- 状態: 提案（提出版には入れない。入れるかは作者が別に決める）
- 日付: 2026-11-07
- 関連: #52、[ADR 0012](0012-open-production-with-usage-limits.md)、[ADR 0014](0014-browser-speech-recognition-for-voice-input.md)、#44（最初の画面は会話が主役）

## 背景

作者が別々に作った道具（さきよみの会話・見通し・渡すもの、札幌の子育て年表、子ども向けのあそび、手元の Persona Studio、かがみ）を、同じアプリとして 1 つのメニューから使いたい。見た目はさきよみに揃える。

満たすこと:

- メニューは全ページで同じものを 1 つだけ。最初の画面は会話が主役のまま（#44）。スマホ幅でも使える
- 会話の途中で年表やあそぶへ移って戻っても、会話・計算結果・利用者が直した文章が消えない。サーバーには保存しない
- 年表は iframe を使わずにページとして出し、`X-Frame-Options: DENY` は残す
- あそぶは 1〜2 歳向けで、画面に見える文字は 0。保存・外への通信・マイク・カメラは無し
- 提出版の会話・計算・プロンプト・検査（`lib/money/` など）と、動画に映る既存の文言は変えない

## 決めたこと

### メニュー

1. **行き先は `lib/menu.ts` にだけ書く。** 話す（`/#talk`）・見通し（`/#outlook`）・渡すもの（`/#hand`）・年表（`/roadmap`）・あそぶ（`/play`）。会話の画面の 3 つと、ほかの道具のあいだに細い区切りを置く。
2. **ヘッダーの「表示の切り替え」をこのメニューに置き換える。** 部品は `app/site-header.tsx` の `SiteHeader` 1 つで、会話の画面と年表のページが同じものを出す。あそぶでは出さない。会話の画面での見た目（丸い枠の今いる場所、件数）は今までのまま。
3. **会話の画面の中は今までどおり `#` だけで移り、ほかのページへは Next.js の `Link` で移る。** ほかのページから会話の画面へは `/#outlook` のように `#` つきで戻る。
4. **ペルソナとかがみは、それぞれ `NEXT_PUBLIC_PERSONA_URL`・`NEXT_PUBLIC_KAGAMI_URL` があるときだけ、別のタブで開く外部リンクとして出す。** 並びはペルソナ、かがみの順で、年表とあそぶのあと。値は http か https の URL だけを通す（`javascript:` などは出さない）。判定は両方で同じ `externalHref` を使う。公開の配置では設定しないので出ない。Persona Studio とかがみのコードはこのリポジトリに入れない。
5. **同じ行き先のリンクを、ナビゲーションとして二重に置かない。** 返答の下の「要る額 …と、まず確かめる 1 つを見る」と、見通し・渡すものの「← 会話に戻る」、空のときの「話す」は、読む流れの中のリンクで、動画に映る文言でもあるので残した。メニューの中の見通しと渡すものは 1 つずつ（テストで確かめる）。

### ヘッダーの幅（PDM の手元の確認のあとに足した）

- **ヘッダーの文字は、どの幅でも途中で折り返さない。** 製品名・「公開の試用版」・「保存とプライバシー」は 1 行のまま。1280px 以上の見た目と文言は変えない（動画に映る）。1079px 以下では副題と「公開の試用版」を隠し、それでも収まらない幅（外部リンクがあれば 959px 以下、無ければ 799px 以下）ではメニューを 2 行目に送る。740px 以下はスマホの並び。ペルソナとかがみを両方出して 2 桁の件数でも、320〜1,440px で折り返しと横のはみ出しが無いことを確かめた
- **狭い幅で収まらないメニューは、メニューの中で横に送る。** 公開の配置の 5 つは 320px と 375px で 1 行に収まる。ペルソナとかがみを足すと、狭い幅ではメニューの中で横に送って最後まで届く（ページは横にはみ出さない）

### 移るあいだの会話の状態

6. **会話の画面の状態を、このタブのメモリ（`lib/kept-workspace.ts` のモジュール変数）に写す。** 写すのは会話・カード（計算の結果と直した文章を含む）・下書き・「このブラウザに保存」の選択・体験例を見ているあいだに預けている自分の会話。変わるたびに写し、会話の画面に戻ったときはここから続ける。サーバーにもブラウザの保存領域（localStorage・sessionStorage）にも書かない。タブを閉じるか再読み込みすると、今までどおり消える（「このブラウザに保存」を選んでいれば localStorage から読む）。
7. **ページの移動を読み込み直しにしない。** `Link` で移ると JavaScript のモジュールが残るので、6 の値も残る。`app/workspace.tsx` の変更は、ヘッダーの差し替えと、読み込みのときにメモリを先に見る数行と、メモリへ写す `useEffect` だけ。送信・計算・検査には触れない。
8. **`#` だけのリンクで足された履歴に、Next.js の印を付け直す（`app/history-sync.tsx`）。** ブラウザが `#` だけのリンクで足す履歴には Next.js の印が無く、年表から「戻る」で `/#outlook` に帰ると、URL だけ変わって画面が年表のまま残った（ブラウザで再現した）。`hashchange` のたびに `history.replaceState` を呼ぶと、Next.js が印を付けるので、「戻る」「進む」で正しいページが出る。

### 年表

9. **正本は `docs/prototypes/sapporo-roadmap.html` のまま、ビルドのときに見た目・画面・動きの 3 つに分けて `/roadmap` に置く（`lib/roadmap-page.ts`）。** iframe は使わない。HTML の動きは `startRoadmap()` にまとめ、ページに入るたびに始め、離れるときに止める（`hashchange` と `popstate` の受け取りと、明るさの設定を外す）。単独で開いたときは今までどおりすぐに始まるので、年表の既存のテストはそのまま通る。
10. **年表の CSS はすべて `.rmp` の中に閉じ、色と文字はさきよみのトークンから作る。** 単独の HTML も `app/globals.css` を読み、さきよみの中と同じに見える。レーン・締切・今日の線・子の印の色は、さきよみの色から濃さを合わせた。**さきよみに暗い表示は無いので、年表も端末の設定にかかわらず明るいトークンで出す。** 試作にあった暗い表示（端末の設定に従う自動と、設定画面の「表示の明るさ」の切り替え）は、作者の「さきよみのトンマナと合わせて」に合わせて外した（PDM の手元の確認で、端末が暗い表示だと年表のページだけ黒くなったため）。
11. **ほかの機能は変えない。** 入力欄はメイン画面に出さず設定画面だけ、初期値は架空の「今日時点で 1 歳の子」と「来年 3 月に生まれる予定の子」、年表を押すと詳細へ飛ぶ、出典 URL と確認日を残す。

### あそぶ

12. **`/play` に選ぶ画面、`/play/pon`・`/play/baa`・`/play/shabon` に 3 つのあそび。** 画面に見える文字は 0（かな・漢字・英数字・記号）。名前は `aria-label` にだけ置き、ツールチップになる `title` も使わない。
13. **戻るのは、隅の家の絵を約 1.5 秒押し続けたときだけ。** 押している間は輪が満ちる。途中で離すか、2 本以上の指が同時に触れたら数え直す。あそびから選ぶ画面へ、選ぶ画面から会話の画面へ戻る。
14. **音は Web Audio でその場で作り、絵はインライン SVG と CSS で新しく描く。** 正弦波と三角波、ペンタトニック、低い音量、柔らかいフィルター、同時に鳴らす数の上限。外部の素材・絵文字・Claude API は使わない。特定の作品・番組・ゲームの名前やキャラクターに似せない。
15. **失敗・得点・時間制限・広告・外へのリンク・外部通信・データ保存・マイク・カメラは無し。** 触れる的は 96px 以上。`touch-action: none`、選択と長押しのメニューと拡大を止める（viewport の拡大禁止、iPhone の Safari のためにピンチの合図も止める）。`prefers-reduced-motion` のときは、形は広がらずにその場に出て消え、しゃぼん玉は浮かばずにその場にいる。
16. **ばあの中身は `app/play/baa/animals.tsx` の `FRIENDS` 配列。** 差し替えると中身が変わる。発達や知育の効果をうたう文言は書かない。

### テスト

17. **ブラウザでの通しの検査を `e2e/app.test.ts` に置き、`npm run test:e2e`（ビルドしてから実行）で走らせる。** `/api/chat` への送信は架空の体験例の返答で差し替え、Claude には送らない。そのために `playwright@1.63.0`（Apache-2.0）を開発用の依存に足した（この作業の環境に入っている Chromium と同じ版）。年表の既存のテストは `npm run test:roadmap` で走らせる。
18. **ペルソナとかがみを出したビルドでも同じ検査を走らせる（`npm run test:e2e:links`）。** 値はビルドのときに埋め込まれるので、`npm run test:e2e`（未設定）とあわせて 2 回走らせて、出る・出ないの両方を確かめる。かがみの URL は検査用の架空の値（`https://kagami.example.com/`）。

## 検討したほかの案

| 案                                                                          | 採らなかった理由                                                                                                                                                                          |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 移るたびに sessionStorage に保存して、読み込み直しのあとで戻す              | 「保存しない（閉じると消える）」の約束が弱くなる。ブラウザによってはタブの復元で残る。移るたびに「このページを離れますか」の確認が出る                                                   |
| 会話の状態を根のレイアウトの Context に持ち上げる                           | `app/workspace.tsx` の状態の持ち方を大きく書き換えることになり、提出版の会話のコードに触れる範囲が広い                                                                                    |
| Next.js の Cache Components（Activity で前のページを残す）を使う            | アプリ全体の描画の決まりが変わる（`/` の `force-dynamic` など）。提出の前日に入れる変更として大きすぎる                                                                                     |
| 年表を iframe で埋め込む                                                    | 依頼で禁止。`X-Frame-Options: DENY` も外すことになる                                                                                                                                        |
| 年表を React で書き直す                                                     | 1,500 行の試作を書き直すと、機能を変えないことを確かめる手間が大きい。HTML を正本に残せば、年表の既存のテストがそのまま使える                                                           |
| メニューをスマホでは「その他」に畳む                                        | 同じ行き先の要素が画面の幅によって 2 か所に出る。公開の配置の 5 つは 320px と 375px の幅で 1 行に収まった（実測）。ペルソナとかがみを足した 7 つは、メニューの中で横に送れば届く |
| 中くらいの幅でもヘッダーの文字の折り返しを許す                              | 「さきよ／み」「公開の／試用版」のように語の途中で折れて読みにくい（PDM の手元の確認で 771px のとき）                                                                                         |
| 家の絵を 1 回押すと戻る                                                     | 子どもの偶然の一押しで戻ってしまう                                                                                                                                                        |

## 結果

- メニューから年表やあそぶへ移り、メニューかブラウザの「戻る」で帰っても、会話・計算結果・直した文章・下書きが残る（ブラウザの通しの検査で確かめた。メモリへ写すのを止めるとこの検査が落ちることも確かめた）
- 送信の途中でほかのページへ移ると、今までどおり送信は中止される。下書きは残るので、送り直せる
- 再読み込みやタブを閉じたときは、今までどおり消える（「このブラウザに保存」を選んだときを除く）
- 年表は、端末が暗い表示でも会話の画面と同じ明るい色で出る。試作の「表示の明るさ」の切り替えは無くなった（保存してあった明るさの値は読まずに捨てる）
- 見直す条件: 提出版に入れるとき（仕様書 `docs/family-preparation.md` と README にメニューのことを書く）。Next.js の履歴の扱いが変わったとき（`app/history-sync.tsx` が要らなくなるか、効かなくなる）
