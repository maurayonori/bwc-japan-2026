# ADR（設計判断の記録）

設計の判断を、理由と一緒に残す場所です。審査の「深さと実行力」はリポジトリを見て判断されるので、何を試し、なぜそう決めたかをここで追えるようにします。

## 書くとき

- 技術・サービス・モデルを選んだとき
- データの持ち方や、Claude に任せる範囲を決めたとき
- やらないと決めたとき（範囲を削ったときも含む）
- 前の判断を覆したとき（古い ADR は消さず、状態を「置き換え」にする）

## 書き方

1. [template.md](template.md) を写し、`NNNN-短い英語の名前.md` で保存する（番号は 4 桁の連番）
2. 状態は「提案」「採用」「却下」「置き換え」のどれか
3. 下の一覧に 1 行足す
