# 現在の製品：さきよみ — 家族のための準備室

2026-11-06 更新。公開の URL は https://sakiyomi-bwc2026.vercel.app （ログイン不要、会話には利用上限あり）。判断の記録は [ADR 0011](adr/0011-confirm-sakiyomi-and-include-money.md)（題材と金額計算）、[ADR 0012](adr/0012-open-production-with-usage-limits.md)（公開）、[ADR 0008](adr/0008-build-family-preparation-workspace.md)（会話とカード）。

## 利用者と困る場面

入院が決まった本人と、その家族。病院の見積もりを受け取っても、制度を知らないと退院の日にいくら要るかを計算できない。同じ時期に、朝の支度や保険の確認を誰にどう頼むかも決めることになる。話せることだけで、準備を一つ進めたい。

療養や長期の不在で家を空ける人も使える。ただし金額の計算は入院だけが対象である。

## 体験

1. 一つの入力欄に普通の言葉で書く。固定の質問票は無い。
2. Claude が分かることと不明なことを分け、カードを作る。必要なら状況に合う問いを 1 つ返す。金額と日付はプログラムが計算する。
3. 右側の「家族のしおり」で、文章、元の言葉、まだ確かめていないこと、次の一歩を読む。
4. 「入院が 1 週間延びたら」のように条件を変えて話すと、変わるところだけ計算し直す。
5. 文章を直す、準備できたものを記録する、渡すものを選ぶ。
6. 選んだ内容を確認画面で読み、コピーまたはテキストで保存する。

スマートフォンでは会話の下にしおりを置く。キーが無いときと上限に達したときも、架空の体験例で操作を試せる。見本の会話を実際の AI の生成と混同しない表示にする。

## 出力の約束

| 種類             | 作るもの                                                               | 未確認として残すもの                 |
| ---------------- | ---------------------------------------------------------------------- | ------------------------------------ |
| お金の見通し     | 高額療養費の上限、食事代、営業日、手元資金をプログラムが計算した見通し | 見積もりと実際の請求の差、給付の有無 |
| 暮らしの引き継ぎ | 朝の支度などの手順、分かっている場所と時刻                             | 担当する人の了承、話されていない手順 |
| 確かめる・頼む   | 窓口への質問文、身近な人への具体的な依頼文                             | 給付の可否、期日、相手の回答と同意   |
| 残しておく言葉   | 利用者が残したいと話した原文                                           | 言っていない感情や出来事は補わない   |

編集・完了・持ち出し選択したカードは保護する。会話やモデルの返答は、外部へ送る文章に含めない。

## Claude とプログラムの分担

| 担当       | すること                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| Claude     | 話から条件を読み取る。分からない値に仮の幅を置く。カードの文章を書く。質問は、答えで結果が変わるときに 1 つだけ |
| プログラム | 金額と日付の計算。引用と原文の照合。返答の金額と日付の照合。カードの保護。持ち出す範囲の限定                    |

値は「確かめた額」「見積もり」「仮定」に分ける。確かめていない入金（給付金や払い戻し）を、手元のお金として数えない場合も並べる。

## 計算の範囲

| 計算         | 範囲                                                                                                                                        | 入れていないもの                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 高額療養費   | 協会けんぽ、70 歳未満、2026 年 8 月〜2027 年 7 月の診療分。1 か月、1 つの医療機関、入院の保険診療分。月をまたぐ入院は月ごとに分けて計算する | 多数回該当、世帯合算、年間上限、国民健康保険などの違い |
| 食事代       | 一般の区分の 1 食 550 円を、1 日 3 食で数えた多めの見積もり                                                                                 | 住民税非課税の世帯などの額                             |
| 日付と営業日 | 土日・祝日・12/31〜1/3 を除いて数える。2026 年と 2027 年だけ                                                                                | 病院や保険会社ごとの休業日                             |
| 手元資金     | 渡された入出金を日付順に並べ、要る額、足りない額、その日を出す。筋書きを並べて比べる                                                        | 民間保険の給付額、傷病手当金の額（確かめる相手を示す） |

幅は置いた仮定の下限と上限で、確率や信頼区間ではない。数値の出典と確認日は[調査メモ](research/hospital-money-facts-20261105.md)にある。

## データの範囲

メッセージ 40 件、本文 1 件 4,000 文字・合計 32,000 文字、カード 24 件、本文 1 件 2,000 文字を上限とする。上限を越えたらメモを持ち出して新しい会話を始める。保存はオプトインの localStorage。キーはサーバーの環境変数または秘密ファイルから読む。公開版の回数の上限は [ADR 0012](adr/0012-open-production-with-usage-limits.md) にある。

## しないこと

診断、治療、入院日数、再発の見通しや確率。心理の助言。給付の可否・額・時期の判断。保険や金融商品のすすめ。連絡と申請の代行。人物の再現。

## これから確かめること

- 実際の準備に使える文章と見通しになっているか。
- 本人の文章を捏造・勝手に上書きしないか。
- 共有の範囲を自分で選べるか。
- 医療・心理への助言や、保証のない金銭的な断定に逸脱しないか。
- 金額が分かると、確認や依頼に動くか（[ADR 0007](adr/0007-test-preparation-through-hospital-cost-simulation.md) の合格条件）。

当事者の評価は未実施である。測るのはメモの件数だけでなく、「一つ確認した」「頼む内容が決まった」「必要な人へ渡せた」などの変化である。不安の解消、継続利用、支払意思は確かめていない。
