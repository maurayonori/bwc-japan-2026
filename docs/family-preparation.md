# 現在の製品：さきよみ — 家族のための準備室

2026-11-07 更新。公開の URL は https://sakiyomi-bwc2026.vercel.app （ログイン不要、会話には利用上限あり）。判断の記録は [ADR 0013](adr/0013-decision-first-range-and-one-check.md)（主役を幅と確認 1 つにする。提案）、[ADR 0011](adr/0011-confirm-sakiyomi-and-include-money.md)（題材と金額計算）、[ADR 0012](adr/0012-open-production-with-usage-limits.md)（公開）、[ADR 0008](adr/0008-build-family-preparation-workspace.md)（会話とカード）。

最上段の幅と確認 1 つは ADR 0013 で決めた仕様で、11/7 の時点では実装を別の作業で進めている。公開中の画面とは違うところがある。

## 利用者と困る場面

入院が決まった本人と、その家族。病院の見積もりを受け取っても、高額療養費が月ごとに計算されることや、窓口で上限を使う条件を知らないと、退院の日にいくら要るかを自分で計算できない。分からないことがいくつもあり、どれから確かめれば見通しが定まるのかも分からない。同じ時期に、朝の支度や保険の確認を誰にどう頼むかも決めることになる。

話せることだけで、「いくら要りそうか」と「まず何を確かめるか」を知り、準備を一つ進めたい。

療養や長期の不在で家を空ける人も、下段の渡すものは使える。ただし金額の計算は入院だけが対象である。

## 体験

1. **話す。** 一つの入力欄に普通の言葉で書く。固定の質問票は無い。分からない値は分からないと言えばよい。
2. **幅を見る。** 最上段に「退院の日に要る額の幅」（下限〜上限）が出る。金額と日付はプログラムが計算する。分からない値には仮の幅を置き、仮定であると書く。
3. **確認 1 つを見る。** 幅の下に「まず確かめる 1 つ」が出る。誰に、何を聞くかの質問文と、確かめたときに縮む額を並べる。どれを出すかはプログラムが決める。
4. **答えを話す。** 窓口で聞いた答えを話すと、その値は「仮定」から「確かめた」に変わる。
5. **縮む。** 計算し直し、縮む前と後の幅を並べる。まだ縮められる不明点があれば、次の 1 つが出る。
6. **渡す。** 下段の「渡すもの」（お金の表、暮らしの引き継ぎ、確かめる・頼む、残しておく言葉）を直す、準備できたものを記録する、渡すものを選ぶ。選んだ内容を確認画面で読み、コピーまたはテキストで保存する。

「入院が 1 週間延びたら」のように条件を変えて話すと、変わるところだけ計算し直す。スマートフォンでは会話の下に幅と確認、その下に渡すものを置く。キーが無いときと上限に達したときも、架空の体験例で操作を試せる。見本の会話を実際の AI の生成と混同しない表示にする。

## 出力の約束

| 種類                                                  | 作るもの                                                                                                            | 未確認として残すもの                                                 |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **退院の日に要る額の幅と、まず確かめる 1 つ（主役）** | プログラムが計算した要る額の下限と上限。幅をいちばん縮める確認 1 つと、確かめても残る幅・縮む額。確認の相手と質問文 | 仮定のまま残る値、話されていない費用、窓口の答えそのもの、給付の有無 |
| お金の見通し（渡すもの）                              | 高額療養費の上限、食事代、営業日、手元資金をプログラムが計算した表と、計算の記録                                    | 見積もりと実際の請求の差、給付の有無                                 |
| 暮らしの引き継ぎ（渡すもの）                          | 朝の支度などの手順、分かっている場所と時刻                                                                          | 担当する人の了承、話されていない手順                                 |
| 確かめる・頼む（渡すもの）                            | 窓口への質問文、身近な人への具体的な依頼文                                                                          | 給付の可否、期日、相手の回答と同意                                   |
| 残しておく言葉（渡すもの）                            | 利用者が残したいと話した原文                                                                                        | 言っていない感情や出来事は補わない                                   |

幅は置いた仮定の下限と上限で、確率ではない。順位の根拠（今の幅、確かめても残る幅、縮む額）と、道具に渡した値とその確かさは、開けば読める。編集・完了・持ち出し選択したカードは保護する。会話やモデルの返答は、外部へ送る文章に含めない。

## Claude とプログラムの分担

| 担当       | すること                                                                                                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude     | 話から条件を読み取る。分からない値に仮の幅を置く。プログラムが選んだ不明点を確かめる質問文を書く（誰に、何を、どう聞くか）。カードの文章を書く。利用者への質問は、答えで結果が変わるときに 1 つだけ            |
| プログラム | 金額と日付の計算。不明点の列挙と順位（確かめても残る幅 `width_if_resolved` と縮む額 `shrink` を `simulate_cashflow` の結果に同梱）。引用と原文の照合。返答の金額と日付の照合。カードの保護。持ち出す範囲の限定 |

不明点の列挙と順位はプログラム、質問文は Claude が受け持つ。Claude に順位を決めさせない。

値は「確かめた額」「見積もり」「仮定」に分ける。答えを話すと「仮定」が「確かめた」に変わり、幅が縮む。確かめていない入金（給付金や払い戻し）を、手元のお金として数えない場合も並べる。

## 計算の範囲

| 計算         | 範囲                                                                                                                                        | 入れていないもの                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 高額療養費   | 協会けんぽ、70 歳未満、2026 年 8 月〜2027 年 7 月の診療分。1 か月、1 つの医療機関、入院の保険診療分。月をまたぐ入院は月ごとに分けて計算する | 多数回該当、世帯合算、年間上限、国民健康保険などの違い |
| 食事代       | 一般の区分の 1 食 550 円を、1 日 3 食で数えた多めの見積もり                                                                                 | 住民税非課税の世帯などの額                             |
| 日付と営業日 | 土日・祝日・12/31〜1/3 を除いて数える。2026 年と 2027 年だけ                                                                                | 病院や保険会社ごとの休業日                             |
| 手元資金     | 渡された入出金を日付順に並べ、要る額、足りない額、その日を出す。筋書きを並べて比べる                                                        | 民間保険の給付額、傷病手当金の額（確かめる相手を示す） |

幅は置いた仮定の下限と上限で、確率や信頼区間ではない。数値の出典と確認日は[調査メモ](research/hospital-money-facts-20261105.md)にある。

## データの範囲

メッセージ 40 件、本文 1 件 4,000 文字・合計 32,000 文字、カード 24 件、本文 1 件 2,000 文字を上限とする。上限を越えたらメモを持ち出して新しい会話を始める。保存はオプトインの localStorage。キーはサーバーの環境変数または秘密ファイルから読む。公開版の回数の上限は [ADR 0012](adr/0012-open-production-with-usage-limits.md) にある。

## しないこと

診断、治療、入院日数、再発の見通しや確率。心理の助言。給付の可否・額・時期の判断。保険や金融商品のすすめ。連絡と申請の代行。人物の再現。

## これから確かめること

[ADR 0007](adr/0007-test-preparation-through-hospital-cost-simulation.md) の合格条件に沿って、「分かった」「選んだ」「進んだ」を分けて確かめる。

| 段階     | 確かめること                                                               | 進んだと数えないもの                         |
| -------- | -------------------------------------------------------------------------- | -------------------------------------------- |
| 分かった | 退院の日に要る額の幅と、まず確かめる 1 つを、本人が自分の言葉で言える      | 画面を開いた、表を見た                       |
| 選んだ   | 確かめる相手と聞くことを決め、質問文を持ち出した。頼む相手と内容が決まった | 質問文を作った、リンクを開いた               |
| 進んだ   | 実際に窓口へ聞き、答えを話して幅が縮んだ。必要な人へ渡せた                 | 聞くつもりになった、申請や連絡を終えたと推測 |

ほかに確かめること。

- 本人の文章を捏造・勝手に上書きしないか。
- 共有の範囲を自分で選べるか。
- 医療・心理への助言や、保証のない金銭的な断定に逸脱しないか。
- 確認の順位が、同じ入力で毎回同じになるか。

当事者の評価は 0 件である。幅と確認 1 つを見て、人が窓口へ聞きに行くかは確かめていない。不安の解消、継続利用、支払意思も確かめていない。
