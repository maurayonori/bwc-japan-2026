# 入院前のお金の見通し（会話で試す、検証用の試作）

2026-11-06。判断の記録は [ADR 0009](../../adr/0009-conversational-hospital-cost-prototype.md)（置き換え済み。[ADR 0011](../../adr/0011-confirm-sakiyomi-and-include-money.md) で本体へ取り込むと決めた）。

入院が決まった人が、状況をそのまま話すと、Claude が条件を読み取り、**金額と日付はプログラムが計算して**、「いつ・いくら手元に要るか」と「先に確かめること」を返す試作です。[ADR 0007](../../adr/0007-test-preparation-through-hospital-cost-simulation.md) の検証（金額と日付が具体的に見えれば、準備に動けるか）を、実際に話して試すために作りました。固定の入力項目はありません。

**この試作の計算は、提出アプリ「さきよみ」の `lib/money/` へ移植した。** ここは経緯として残している。製品のコードはリポジトリ直下を読む。

## 動かす

Node.js 22 以降が必要です。

```sh
cd docs/prototypes/hospital-conversation
npm ci
npm test     # Claude API は呼ばない
npm start    # http://127.0.0.1:8791 を開く
```

鍵は、リポジトリ直下の `.env.local`（無ければ `.env`）から読みます。提出アプリと同じ設定をそのまま使えます。シェルに export する必要はありません。鍵が無くても画面は開けます（会話を送ると、設定のしかたを案内します）。

| 変数                     | 意味                                                                  | 既定                                                |
| ------------------------ | --------------------------------------------------------------------- | --------------------------------------------------- |
| `ANTHROPIC_API_KEY`      | API キー                                                              | なし                                                |
| `ANTHROPIC_API_KEY_FILE` | キーを書いたファイルの絶対パス。`ANTHROPIC_API_KEY` が無いときに使う  | なし                                                |
| `HOSPITAL_CHAT_MODEL`    | この試作だけのモデル指定                                              | `ANTHROPIC_MODEL`、それも無ければ `claude-opus-5-5` |
| `HOSPITAL_CHAT_EFFORT`   | 考える深さ。`low` / `medium` / `high` / `xhigh` / `max`               | `medium`                                            |
| `HOSPITAL_CHAT_BETA`     | `off` にすると、ベータの機能（下の「Claude API の使い方」）を使わない | 使う                                                |
| `HOSPITAL_CHAT_PORT`     | 待ち受けるポート                                                      | `8791`                                              |

API を呼ばずに、計算と指示だけを確かめることもできます。

```sh
npm run tool        # 道具の一覧
npm run tool -- kougaku_gendo '{"treatment_month":"2026-12","income_category":"ウ","amount_basis":"copay","amount_low":300000,"amount_high":300000,"copay_percent":30}'
npm run prompt      # Claude に渡す指示の全文
```

## Claude がすること・プログラムがすること

| 担当               | すること                                                                                                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude             | 話から条件を読み取る。分からない値に仮の幅を置く。どの計算を、どの筋書きで並べるかを決める。結果の意味と、次に確かめることを言葉にする。質問は、答えで見通しが変わるときに 1 つだけ          |
| プログラム（道具） | 高額療養費の上限と窓口で払う額（`kougaku_gendo`）、食事代（`meal_cost`）、日付・日数・営業日（`calc_date`）、支払いと入金を並べた「手元に要る額・足りない額・その日」（`simulate_cashflow`） |
| プログラム（検査） | 返答に書かれた金額と日付が、道具の入出力・利用者の発言・持っている事実のどれかにあるかを照らす。見当たらなければ、返答の下に注意を出す（`src/guard.mjs`）。返答は止めない                    |
| 画面               | 返答の下に、道具の計算結果を表で出す。前提・含まれない費用・出典と確認日も一緒に出す。返答の `[F03]` のような番号は、出典へのリンクになる                                                    |

値は「確かめた額」「見積もり」「仮定」に分けて扱います。確かめていない入金（給付金や払い戻し）は、手元のお金として数えない場合も並べます。

## データの扱い

- 書いた文章と、それまでの会話は、返答を作るために Anthropic の API へ送られます。デモや評価では、架空の内容で試してください。
- サーバーは `127.0.0.1` だけで待ち受け、Host と Origin を確かめて、この端末のこの画面からのリクエストだけを受けます。一般公開する作りではありません。
- 会話はメモリの中にだけ置きます。ファイル・データベース・ブラウザの保存領域には書きません。サーバーを止めるか「新しい会話」を押すと消えます。
- ログには、会話の本文・鍵・API のエラー本文を出しません。出すのは、アプリが分類したエラーの種類と状態コードだけです。
- 画面は、外部のスクリプト・フォント・画像を読み込みません。

## 計算の範囲

計算に使う数値は `src/rules.mjs`、会話で使う事実は `src/facts.mjs` にあり、どちらも出典の URL と確認日を持ちます。調べた経緯は[調査メモ](../../research/hospital-money-facts-20261105.md)にあります。

- **高額療養費**: 70 歳未満、全国健康保険協会（協会けんぽ）の表、2026 年 8 月〜2027 年 7 月の診療分。1 か月・1 つの医療機関・入院の保険診療分。多数回該当、世帯での合算、年間の上限は入れていません。国民健康保険やほかの健康保険組合では、区分の決まり方や上乗せの給付が違うことがあります。
- **食事代**: 一般の区分の 1 食 550 円（2026 年 6 月 1 日から）を、1 日 3 食で数えた多めの見積もり。
- **営業日**: 土日・祝日・12/31〜1/3 を除いて数えます（銀行の休日と同じ）。2026〜2027 年だけに対応。病院や保険会社の休業日は、これと違うことがあります。
- **計算しないもの**: 民間の保険の給付金、傷病手当金、払い戻しの額と日付。利用者が言った値か、仮に置いた値を、「確かめていない入金」として並べるだけです。差額ベッド代や文書料も、利用者が言えば支払いの行として入ります。
- **幅**は、置いた仮定の下限と上限です。確率や信頼区間ではありません。

## しないこと

- 医療の助言。病気、治療、入院日数、再発についての見通しや確率は言いません（大会の「作らないもの」にも当たります）。
- 給付金が出るか・いくら出るか・いつ入るかの判断。確かめる相手と、聞き方までを出します。
- 特定の保険や金融商品のすすめ、病院や保険会社への連絡・申請の代行。
- 資料を検索して答える仕組み（RAG）。持っている事実は、出典を確かめた短い一覧を、指示の中にそのまま入れています。

## 作り

```
src/
  dates.mjs  validate.mjs      日付の足し引き、入力の確かめ
  rules.mjs                    計算に使う数値（限度額の表、食事代、祝日）と出典
  kougaku.mjs  meals.mjs  business-days.mjs  ledger.mjs    4 つの計算
  tools.mjs                    Claude に渡す道具の定義（strict）と、道具の実行
  facts.mjs                    会話で使う事実と出典
  prompt.mjs                   Claude に渡す指示
  conversation.mjs             1 回の発言から返答までの往復（道具の実行を含む）
  claude.mjs                   Claude API の呼び出し、設定、エラーの日本語化
  guard.mjs                    返答の金額と日付の検査
  server.mjs                   この端末だけで動く HTTP サーバー
  cli.mjs                      API を呼ばずに、道具と指示を確かめる入口
public/                        画面（フレームワークなしの HTML・CSS・JS）
test/                          node:test のテスト
```

### Claude API の使い方

- 公式の SDK（`@anthropic-ai/sdk`）で Messages API を呼び、道具の往復は自前のループで回します。テストでは、用意した応答を順に返す代役を渡して、API を呼ばずに往復を確かめています。
- 思考（adaptive thinking）は有効のまま。`output_config.effort` を明示しています。
- **履歴は後ろに足すだけ**にしています。Claude Opus 5.5 / Sonnet 5.5 の思考ブロックは、それより前の system・tools・messages が変わると使えなくなるためです。system と tools はセッションの最初に決めて変えず、応答の content は思考ブロックごとそのまま履歴に入れます。拒否・未完の道具呼び出し・文章なしで終わった往復は履歴に入れません。文章だけが途中で切れた場合は、注意とともに残し、続けられるようにします。
- 変わらない部分（指示と道具の定義）は、プロンプトキャッシュに乗せています。今日の日付は、キャッシュの境目のあとに置いています。
- ベータの機能を 2 つ使います。どちらも、API が受け付けなければ、使わない形に切り替えて続けます（画面に「ベータの機能なしで動作」と出ます）。
  - `server-side-fallback-2026-07-01`: 安全上の理由でモデルが返答を断ったとき、API が代わりのモデルで同じリクエストをやり直す。代わりのモデルが答えたときは、返答にその旨を出します。
  - `thinking-binding-controls-2026-08-01`: 履歴が変わったと API が判定したとき、エラーにせず、その思考ブロックを落として続ける。落としたときは、返答に注意を出します。

## 確かめたこと・確かめていないこと

確かめたこと（2026-11-06）:

- `npm test` の 131 件が通る。計算（限度額の 5 区分、端数、月の範囲、営業日と年末年始、同じ日の入出金の順、確かめていない入金の扱い）、道具の定義、会話の往復、サーバー（この端末以外からの拒否、入力の上限、鍵なし、API の失敗、同時の送信、応答待ちを含むセッション上限、ログへのエラー本文の非出力）、返答の検査、CLI。
- 資金繰りの計算を、日付ごとに集計する別実装と、固定シードの架空入力 1,000 組 × 3 条件で照合し、3,000 件一致した。
- 会話が引用する事実 16 件の本文と出典を照合。認定証の期限、診断書を省ける条件、支払時期、差額ベッド代の条件と根拠 URL を修正した。確認日は画面の一覧に表示する。
- 実際のブラウザ（ヘッドレスの Chrome）で、用意した応答を返す代役サーバーを相手に、送信・返答・計算結果の表・注意・API の失敗・拒否・新しい会話を操作した。幅 390px で横にはみ出さない。外部への通信と CSP 違反は無い。利用者の入力に入れた HTML は、文字として表示される。
- 実際の Claude API（`claude-sonnet-5-5`、架空の内容）で会話した。結果は[ワークログ](../../worklog/20261106.md)に書いた。
- 出典修正後にも実 API で 3 往復を確認。必要額を 4 つの道具で計算し、診断書不要の断定と、給付の入金日を確約として扱うことを避けた。未確認の保険金は手元資金に含めなかった。

確かめていないこと:

- **当事者が使って、準備に動けるか。** これが ADR 0007 の検証そのもので、この試作は、そのための道具です。動くことは、役に立つことの証拠ではありません。
- 長い会話（10 往復を超えるもの）、モデルが返答を断ったときの実際の動き、代わりのモデルへの切り替え。テストでは代役で確かめただけです。
- 返答の長さと確認済みの条件の扱いには改善の余地がある。修正後の実 API の返答は 699〜887 字で、窓口で上限を使えると伝えていても、再確認を提案した。
- `claude-opus-5-5` での動作。協会けんぽ以外の健康保険、70 歳以上。
- 人の目での画面の確認は、スクリーンショットだけです。読み上げソフトでは試していません。
- 制度や契約の個別適用。出典と突き合わせたことは、その人への適用や給付を保証するものではありません。
