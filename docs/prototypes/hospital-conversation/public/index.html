この試作について

入院が決まったあと、「いつ・いくら手元に要るか」と「先に確かめること」を、話しながら見通すための試作です。状況をそのまま書くと、Claude が条件を読み取り、金額と日付はプログラムが計算します。

  • 書いた文章は、返答を作るために Anthropic の API へ送られます。デモや評価では、架空の内容で試してください。
  • このサーバーはこの端末の中だけで動き、会話をファイルに残しません。「新しい会話」を押すか、サーバーを止めると、会話は消えます。
  • 医療の助言はしません。給付金が出るか・いくら出るかも判断しません。出すのは、見通しと、確かめる相手・聞き方までです。
  • 計算は、70 歳未満・協会けんぽの表（2026 年 8 月〜2027 年 7 月の診療分）にもとづく概算です。
