# がん疑いから手術準備までに生じたことの事実レポート

- 作成日: 2026年11月3日（JST）
- 対象期間: 2026年6月〜11月3日までの相談記録
- 対象: 法人経営と個人事業を行う本人1名
- 保存先: `maurayonori/bwc-japan-2026/docs/research/cancer-experience-facts-20261103.md`

## 目的と記録の範囲

本人が、がん疑いから手術準備までに経験した手続き上の出来事、相談した疑問、当時の懸念を記録する。後で課題を検討するための資料とし、この段階では課題仮説、原因分析、解決策、機能案、優先順位を加えない。

ここでの「事実」は、本人がそのように話した・質問したという会話上の事実を指す。医療上の診断、保険の給付条件、制度上の適用、病院の請求額を独立に確認した記録ではない。相談日と、実際に検査・問い合わせなどを行った日が同じとは限らない。

氏名、病院名、住所、連絡先、保険の契約番号は記載していない。親族についても、手続きに必要な関係だけを残している。本資料は本人の保存依頼に基づく調査記録であり、デモや評価の入力データには使用しない。

## 記録の読み方

| 区分 | 意味 |
| --- | --- |
| 本人申告の出来事 | 本人が、説明を受けた・電話した・照会できなかったなどと述べたこと |
| 当時の疑問・懸念 | 本人が質問したこと、起こる可能性を心配したこと。被害や損失の発生を意味しない |
| 当時の予定・見積もり | 相談時点の予定や試算。実施済み・支払済み・現在も有効とは扱わない |
| 会話内の確認情報 | 過去の会話で確認済みとして整理されたが、今回は証券などの原資料を閲覧していない情報 |

引用符付きの本人発言は、今回の会話に示された抜粋から転記した。過去の会話を検索して得た履歴要約に基づく内容は、逐語引用にせず要約で記載した。出典番号は末尾の「出典となる相談」に対応する。

## 当時の状況

本人は法人の代表者であり、個人事業も行っていた。2026年6月の相談では、生活費を個人事業の収入で賄っていると説明していた。[S1]

甲状腺の検査について、本人は「がんの可能性が高いが、手術まで断定できない」という趣旨の説明を受けたと述べていた。10月5日の相談でも、まだ確定診断ではなく「疑い」の段階だと訂正している。したがって本資料では、術後病理による診断確定や、転移の有無を確認済みとは扱わない。[S3][S4]

10月16日には、11月の入院・手術を見込んで費用と手続きを相談していた。手術や退院の実施結果、保険請求の完了、給付金の入金結果は、今回の記録から確認できない。[S7][S8]
