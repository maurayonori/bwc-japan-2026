# 仕様書（初版 2026-11-04）

11/3〜4 に Claude Code の質問ツールで作者に聞き取りをして作った。題材は [ADR 0002](adr/0002-topic-gaps-left-by-existing-apps.md)、進め方は [plan.md](plan.md)。末尾に「決まったこと」「まだ決まっていないこと」の一覧がある。当事者への聞き取り（#8）の結果で直す。

## 1. 誰の、何を解くか

- 使う人: 札幌市で就学前の子どもを育てる親。保育園に通っているかは問わない
- 困りごと: 手続き・お金・任意接種・預け先の事前登録を、時期ごとに知らずに損をする、または直前に慌てる。既存のアプリ（母子モ・ピヨログ・ルクミー）はここを扱わない
- 解き方: 子どもの生年月日・区・親の働き方・保育園の有無から、その家庭が「今やること」を期日の近い順に出す。済んだことは一言で消せる。各項目に費用・窓口・出典・確認日が付く

## 2. 範囲

### 出すもの

| 領域                 | 例                                                                                        | 優先              |
| -------------------- | ----------------------------------------------------------------------------------------- | ----------------- |
| 手続きとお金         | 出生届・児童手当・子ども医療費助成・育休給付・保育園の申込・保育料                        | 1                 |
| 任意接種の時期と費用 | インフルエンザ・新型コロナ・おたふくかぜ・RS ウイルスなど。何か月から・何回・いくら・助成 | 1                 |
| 預け先の事前登録     | 病児保育（テオテの登録と施設登録）・子サポ（説明会と顔合わせ）・緊サポ・ショートステイ    | 2                 |
| 発達の目安           | 離乳食の開始時期など。時期の目安だけで、医療・栄養の助言はしない                          | 3（時間があれば） |

- 子どもの時期は出生から就学前まで。最初の版のデータは 0〜2 歳を厚くする。妊娠中の手続きは入れない
- 時間が足りないときは優先 3 → 2 の順に削る。削った判断は ADR に残す

### 出さないもの

[ADR 0002](adr/0002-topic-gaps-left-by-existing-apps.md) のとおり。定期接種のスケジュールと記録・健診・日々の記録・園との連絡・接種や受診をすべきかの判断・離乳食の献立や量・手続きの代行・写真の読み取り。

## 3. 画面と流れ

スマホで開く Web アプリ。日本語だけ。

1. **最初の設定（1 画面）**: 子どもの生年月日・住んでいる区・親の働き方（親ごとに 1 つ）・保育園に通っているか。子どもは「もう 1 人足す」で 2 人まで
2. **今やること**: 期日の近い順の一覧。過ぎたものは消さず赤で残す。各項目に、期日・費用と助成・窓口（区に合わせたもの）・出典 URL・確認日。領域で絞り込める。通知はしない。開いたときに見る
3. **一言で済みにする**: 画面下の入力欄に「インフル 1 回目打った」「児童手当出した」と書く → Claude が項目と日付の候補を返す → 確認して反映。確認せずには反映しない
4. **項目を開く**: 家庭の状況に合わせた短い説明（Claude）と、質問欄。答えはその項目の出典の範囲に限り、範囲を超える質問には窓口を案内する
5. **設定**: 家庭のデータの書き出し（JSON）・読み込み・消去。配偶者との共有は書き出しで行う

## 4. データ

### 家庭のデータ

- ブラウザの中にだけ置く（サーバーに個人情報を置かない。ログインも無い）
- 子ども（生年月日・名前は任意）・区・親の働き方・保育園の有無・済みの記録（項目 id・日付）
- 複数の子どもに広げられる形にし、画面は 2 人まで

### 制度データ

- 開発中に Claude Code のサブエージェントが札幌市・北海道・国の公式ページから起こし、人が確かめて YAML に入れる。実行時はファイルを読むだけで、Claude は公式ページを読まない
- 1 項目が持つもの: id・領域・名前・対象の条件（月齢の範囲・働き方・保育園の有無）・期日の決まり方・準備に要る日数・費用と助成・窓口（区ごとのリンク）・出典 URL・確認日・補足
- 期日の決まり方は 4 種類: 出生から N 日（出生届・児童手当）／月齢で始まる（接種）／毎年の時期（インフルエンザ）／申込の時期（保育園）
- 出典 URL と確認日が無い項目はテストで落とす
- 制度は札幌市のみ。データに自治体の欄を持ち、ほかの市を足せる形にしておく。区で変わるのは窓口と施設へのリンクだけで、制度本体は全市共通で持つ

## 5. 計算

- 対象になるか・期日がいつか・近い順の並びは、すべてプログラム（純粋な TypeScript の関数）で計算する。Claude には生成させない
- 入力は家庭のデータと制度データだけ。同じ入力なら同じ結果になる

## 6. Claude の役割

| 役割               | 入力                             | 出力                             | 触らないもの     |
| ------------------ | -------------------------------- | -------------------------------- | ---------------- |
| 一言の解釈         | 一言と、候補になる項目の一覧     | 項目 id と日付の候補（確認用）   | 反映そのもの     |
| 次の一手の説明文   | 計算で出た項目と期日、家庭の状況 | 「今週はこれ」の短い説明         | 日付・対象の判定 |
| 項目の質問への答え | 質問と、その項目の出典の本文     | 出典の範囲の答え。範囲外は窓口へ | 出典に無いこと   |
| データの鮮度点検   | 制度 YAML と出典 URL             | 公式ページとの差の報告           | YAML の書き換え  |

- Claude には生年月日を送らない。月齢と候補項目だけを渡す
- 鮮度点検は Claude Managed Agents で作る。本体が動いてから（11/7）着手し、間に合わなければ Claude Code のサブエージェントで代用する
- モデルは実装時に claude-api スキルで最新を確かめ、ADR に書く

## 7. 技術と配置

- Next.js + TypeScript。日付計算は画面から切り離した純粋な関数
- Vercel に公開する。Claude の呼び出しだけサーバーレス関数を通し、鍵は Vercel の環境変数に置く。関数には利用量の上限を付ける
- Claude が応答しないときも、一覧と計算は動く

## 8. テスト

- 表形式のテストケース: 生年月日・区・働き方・保育園の有無 → 出る項目と期日。CI で回す
- 制度 YAML の形の検証: 出典 URL・確認日・期日の決まり方の欠落を落とす

## 9. デモ（3 分）

- 架空の家庭: 2026 年 7 月上旬生まれ（デモ日に生後 4 か月）・母が育休中・保育園は未定・札幌市内の区
- 流れ: 開く → 今やることが出る → 一言で済みにする → 次の一手が変わる。出典と確認日が見えることを一瞬映す
- 台本は [submission/demo-script.md](submission/demo-script.md)

## 決まったこと

聞き取りで作者が選んだもの。

1. 対象は出生〜就学前。データは 0〜2 歳を厚く。妊娠中は入れない
2. 厚くするのは手続きとお金・任意接種・預け先の事前登録。発達の目安は時間があれば（最初に削る）
3. 「次の一手」が変わる軸は、親の働き方・保育園の有無・住んでいる区
4. 通知はしない。開いたときに近い順で見せる。過ぎたものは赤で残す
5. 済んだことは自由文の一言を Claude が項目に当て、確認してから反映する
6. 子どもは 2 人まで。データは複数に広げられる形
7. スマホで開く Web アプリ。日本語だけ
8. 家庭のデータはブラウザの中だけ。共有は JSON の書き出し・読み込み
9. 制度データは Claude が公式ページから起こし、人が確かめて YAML に。出典 URL と確認日が必須
10. Claude の役割は、一言の解釈・次の一手の説明文・項目の質問への答え・データの鮮度点検。日付と対象判定には触らない
11. Vercel に公開。Claude の呼び出しはサーバーレス関数。鍵は環境変数
12. Managed Agents は鮮度点検に使う。本体が動いてから（11/7）
13. テストは表形式のケースと、制度ファイルの形の検証
14. Next.js + TypeScript
15. デモは生後 4 か月・母が育休中・保育園未定の架空の家庭で、「開く → 今やること → 一言で済み → 次の一手が変わる」
16. 名前はひらがなの短い名前（決定は #2）

聞き取りでは聞かず、仕様を書くときに決めたもの（異論があれば直す）。

17. 制度は札幌市のみ。データに自治体の欄を持つ。区で変わるのは窓口と施設へのリンクだけ
18. 働き方は親ごとに 1 つ: 育休中／復職予定（時期つき）／働いている／自営／働いていない
19. Claude には生年月日を送らない。月齢と候補項目だけ
20. 期日の決まり方は 4 種類（出生から N 日・月齢で始まる・毎年の時期・申込の時期）
21. Claude が応答しないときも一覧と計算は動く
