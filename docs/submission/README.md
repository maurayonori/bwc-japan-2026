## 提出前のチェックリスト

- [ ] デモ動画が 3 分以内で、公開設定になっている
- [ ] 動画の冒頭 20 秒で「誰の、どんな課題を、どう解くか」を示している
- [ ] デモに映る機能はすべて期間中に作ったもので、このリポジトリにある
- [ ] README に、作るもの・動かし方・Claude の使い方を書いた
- [ ] 秘密情報と個人情報が、ファイルにもコミット履歴にも無い（`git log -p` で確かめる）
- [ ] ドキュメント・画面・動画がすべて日本語
- [ ] 提出フォームのすべての項目を、[form.md](form.md) から写した
- [ ] 締切（20:00）より前に送信した。送信後、フォームの控えを残した（#7）
