# デモ動画の台本（3 分）

審査では、デモ動画が成果を伝える「ほぼ唯一の手段」とされています。3 分以内に収め、冒頭で「誰の、どんな課題を、どう解くか」が分かるようにします。ここでは時間の割り振りだけを先に決めておき、中身は題材が決まってから書きます。

## 時間の割り振り

| 時間       | 見せること                                                         | 中身       |
| ---------- | ------------------------------------------------------------------ | ---------- |
| 0:00〜0:20 | 誰の、どんな課題か。どれくらい困っているか                         | （未記入） |
| 0:20〜0:40 | なぜこの課題なのか（当事者か、どの現場から出発したか）             | （未記入） |
| 0:40〜2:10 | 実際に使っている画面。前提知識の無い人にも流れで価値が分かるように | （未記入） |
| 2:10〜2:40 | Claude をどう使ったか。何ができるようになったか                    | （未記入） |
| 2:40〜3:00 | ハッカソンのあと、誰が使い続けるか                                 | （未記入） |

## 撮影の前に確かめること

- 画面に映るものは、すべて期間中に作ったもので、このリポジトリにある
- 画面に秘密情報・個人情報・実在の人物のデータが映っていない（架空のデータを使う）
- 音声・字幕・画面の文言が日本語
- 公開設定（審査員と参加者が見られる）にした
