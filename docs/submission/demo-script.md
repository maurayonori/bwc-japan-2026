# デモ動画の台本（3 分、v2）

**言いたいこと: 制度を知らなくても、普通の言葉で話せば、支払日にいくら要るかと、まず確かめる 1 つが出て、家族と窓口に渡せる形になる。**

審査では、デモ動画が成果を伝える「ほぼ唯一の手段」とされています。3 分以内に収め、冒頭 20 秒で「誰の、どんな課題を、どう解くか」を言い切ります。

## 形式

- 曲に合わせて文字と録画が動く。**音声ナレーションは無い。** 文字がナレーションの代わりになる
- 画面に出す語は、1 秒 8 字を目安にする。下の表の「秒」は拍に合わせて動かしてよいが、この目安は超えない
- 筋は 1 つの場面で始めて、同じ場面に戻って終わる。場面は「来月の入院が決まった夜。病院の見積もりと保険の書類が手元にあり、何から手をつければいいか分からない」
- 実際の画面の録画は、本番 URL（https://sakiyomi-bwc2026.vercel.app ）で実際の Claude と会話して撮る。返答を待つ時間は切る
- v1（11/6 録画、11/7 限定公開）は再定義の前の画面。v2 は 11/7 の夜に支払日の表（ADR 0016）へ画面を合わせてから録り直したもので、発言の順も「病院の答え」を 2 番目にした

## 架空の人物と発言（確定）

架空の人物: 40 代の会社員。健康保険は協会けんぽ。夫と小学生の子どもの 3 人暮らし。人物、日付、金額はすべて新しく作った架空のもので、実在の人の記録を使っていない。発言 1 と 4 は、アプリの「架空の体験例」と同じ文。

**発言 1（場面 2）**

> 12月14日に入院して、28日に退院する予定です。病院の見積もりだと、医療費は総額で80万円くらい。協会けんぽで、給料は月35万円くらいです。すぐ使えるお金は20万円。保険にも入っていて書類は青いファイルにあるけど、給付金がいつ入るのか分かりません。朝はいつも私が子どもの支度をしています。7時に起こして、着替えは寝室の白い棚、水筒はかばんの横、8時10分に家を出ます。夫に頼みたいけど、何をどう伝えればいいか。

**発言 4（場面 4。病院の答え）**

> 病院に聞いたら、マイナ保険証で窓口の上限は使えると言われました。

**発言 2（場面 5）**

> 入院が1週間延びて、退院が1月4日になったら？

v1 にあった「カードに足す 1 行」と発言 3（自分で直す場面）は、v2 では映さない。直した文章が上書きされないことは README と仕様に書く。

## 台本に出す金額

2026-11-07 の夜に、本番と同じ API で発言 1 → 4 → 2 を通した値で、アプリの体験例（`lib/example.ts`）と同じ計算。**録り直して値が変わったら、録画の値に合わせます。** 月の内訳（発言 2 のあと）は Claude が仮に置くので、変わることがあります。

| 条件（総額 80 万円、区分ウ、手元 20 万円）   | 保険診療分      | 食事代    | 要る額     | 手元との差        |
| -------------------------------------------- | --------------- | --------- | ---------- | ----------------- |
| 12/14〜12/28（15 日）、窓口で上限が使える    | 90,940 円       | 24,750 円 | 115,690 円 | 84,310 円残る     |
| 12/14〜12/28（15 日）、窓口で上限が使えない  | 240,000 円      | 24,750 円 | 264,750 円 | 64,750 円足りない |
| 12/14〜1/4（22 日）、上限が使える、12 月に寄る | 90,940 円     | 36,300 円 | 127,240 円 | 72,760 円残る     |
| 12/14〜1/4（22 日）、上限が使える、費用が半々 | 86,940 × 2 か月 | 36,300 円 | 210,180 円 | 10,180 円足りない |

上限が使えない場合の差額 149,060 円は、この仮定であとから払い戻される見込みの額です。受けられるか、いつ入るかは、加入している健康保険に確かめます。協会けんぽは払い戻しまで[診療月から 3 か月以上](https://www.kyoukaikenpo.or.jp/faq/benefit/004/index.html)と案内しています（確認 2026-11-07。画面の表にも出典つきで出る）。発言 4 のあとは筋書きが 1 本になり、「まず確かめる 1 つ」は「幅はありません。」になる。発言 2 のあと、11/7 21:03 の本番の録画では Claude が 2 つの筋書き（費用が片方の月に寄る 127,240 円、12 月と 1 月に半分ずつ 210,180 円）を並べ、まず確かめる 1 つは月ごとの費用の内訳（幅 82,940 円 → 0 円）になった。20:45 の手元のリハーサルでは 12/28 退院のままの筋書きも残して 3 本（幅 94,490 円）だった。月の内訳の置き方は Claude が決めるので、回によって筋書きの数が変わる。

## 撮影の前に確かめること

- #55（支払日に要るお金の表、体験例、副題）が本番に入っている。ログインせずに開ける
- 発言 1 → 4 → 2 を本番で一度通し、この台本の語を、画面の実際の名前と金額に合わせて直す（手元のリハーサルは 11/7 20:43〜20:46 に済み。値は上の表のとおり）
- 端末ごとの上限は 1 日 20 回。本番の通しは 3 回使う。リハーサルで使い切らない
- 映すものはすべて期間中に作ったもので、このリポジトリにある
- 画面に秘密情報、個人情報、実在の人物のデータが映っていない
- 字幕と画面の文言が日本語
- 曲の利用条件を確かめ、下の「使った素材」に書いた
- 公開設定（審査員と参加者が見られる）にした

**見せないもの**: 送信、申請、予約、カレンダー、写真の読み取りは実装していないので、この台本にも動画にも入れない。
