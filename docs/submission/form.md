## プロジェクト名

さきよみ — 家族のための準備室

## 選んだテーマ

2「本来、誰にでも届くべきものを」。越える壁は専門知識と手続きです（[ADR 0011](../adr/0011-confirm-sakiyomi-and-include-money.md)）。

## プロジェクトの概要

### 一文

入院が決まった人に、還付を待つ間のお金まで用意する負担が生じることがあります。さきよみは、普通の言葉から支払いの見通しを計算し、使える制度の確認と必要な手続きにつなげます。使える制度を、支払日に間に合う準備へつなぐアプリです。

### 誰の、どんな課題か

入院が決まり、まとまった立替が家計の負担になる本人と家族の課題です。特に、窓口で医療費の上限を使えるかを、まだ確かめていない人です。

高額療養費（1 か月の医療費の自己負担に上限を設ける制度）には、あとで払い戻しを受ける方法と、窓口での支払いを上限までに抑える方法があります。窓口で上限を使わないと、上限を超えた分を還付まで立て替えることになります。協会けんぽは、払い戻しまで「診療月から3か月以上かかります」と案内しています（[よくある質問](https://www.kyoukaikenpo.or.jp/faq/benefit/004/index.html)、2026-11-07 確認）。病院の見積もりを受け取っても、自分の場合にいくら違うのか、支払日に手元のお金で足りるのかは、制度を知らないと計算できません。

規模と困りごとの存在を示す数字です。

- 協会けんぽの 2025 年度の実績で、高額療養費のあとからの払い戻し（償還払い）は 104 万 2 千件、283 億円でした。窓口での適用（現物給付）は 460 万 5 千件、6,628 億円です（[令和 7 年度事業報告書 p.17](https://www.mhlw.go.jp/content/12400000/001748917.pdf#page=22)、2026-11-07 確認）。償還払いには外来や世帯の合算も含み、全額が避けられる立替ではありません。
- 過去 5 年に入院した 675 人のうち、窓口で上限までを払った人が 49.6%、いったん払って後から払い戻しを受けた人が 17.9% でした。自己負担は平均 18.7 万円です（[生命保険文化センター 2025 年度調査 p.60〜64](https://www.jili.or.jp/files/research/chousa/pdf/r7/2025honshi_all-.pdf)、2026-11-07 確認）。
- がんと診断されたとき働いていた 831 人の調査では、治療と仕事の両立で困難だったことの最多が「治療費が高い、治療費がいつ頃、いくらかかるか見通しが立たない」34.5% でした（[東京都 2014 年公表 概要版](https://www.gan-portal.metro.tokyo.lg.jp/uploads/01_260527_gaiyou.pdf)、2026-11-07 確認）。

これらは困りごとの存在と規模を示す数字で、アプリで減らせる割合ではありません。東京都の調査は対象が限られ、2013 年の実施です。

### なぜ自分が取り組むのか

作者自身が入院の準備で、いくら要るのか、誰に何を頼むのかを整理しようとしたことが出発点です。

### 何を作り、何が変わるか

普通の言葉で話すと、支払日に要るお金をプログラムが計算し、使える制度の確認と準備につなげる Web アプリを作りました。入力欄は 1 つで、制度の名前を知らなくても始められます。医療や給付の判断はしません。

架空の例です。2026 年 12 月に 15 日入院し、協会けんぽ、所得区分ウ、保険診療の総額 80 万円、入院のために使えるお金が 20 万円の人の場合、支払日に要るお金は次のとおりです。

- 窓口で上限を使えば 115,690 円で、手元から 84,310 円残ります。
- 使わずにあとで還付を受けるなら 264,750 円で、64,750 円足りません。
- 差の 149,060 円が、窓口で上限を使えば避けられる一時立替です。

アプリが担うのは、次の 4 つです。

1. **計算**: Claude が話から条件を読み取り、高額療養費の上限、食事代、日付、手元のお金の見通しをプログラムが計算します。2 つの方法の額と差を並べ、確かめた額・見積もり・仮定を分けて見せます。
2. **質問文**: 幅をいちばん縮める確認をプログラムが 1 つ選び（この例では、窓口で上限を使えるか）、病院の会計にそのまま見せられる質問文を Claude が書きます。
3. **準備の支援**: 入院の受付でマイナ保険証を出す、使えないときは限度額適用認定証を申請する、といった次の一歩を、出典つきで示します。
4. **回答後の更新**: 「病院に聞いたら、マイナ保険証で窓口の上限は効くと言われました」と話すと計算し直し、要る額の幅が 149,060 円から 0 円に縮んだことを伝えます。

本人が窓口で確認と手続きを進め、窓口での適用につながるところまでが一巡です。アプリは連絡も申請もしません。

規模感として、架空の例の差 149,060 円が 100 件なら 14,906,000 円（約 1,491 万円）の立替を避ける計算になります。これは規模感で、達成予測ではありません。償還払いを件数でならすと 1 件あたり約 2.7 万円で、架空の例よりずっと小さい額です。測るものは、新たに窓口適用につながった件数、避けられた立替額、支払日の不足が解消した件数の 3 つです。

本筋のあとに、家族の道具があります。朝の支度などの引き継ぎや質問文、残しておきたい言葉を、自分で直して、選んで渡せます。直した文章は、話を続けても上書きされません。子育ての手続きの年表や、小さな子のためのあそびにも、同じメニューから移れます。

効果は確かめていません。当事者の評価は未実施で、確かめたのは、動くことと計算が合うことまでです。デモと公開データの人物と金額は、すべて架空です。

### ハッカソンのあと、誰が使い続けるか

入院は毎月起きることではないので、毎日開く道具にはしません。入院が決まってから、退院後の請求が終わるまでの数週間に使う道具です。最初に試してほしいのは、入院が決まった本人と、代わりに段取りを進める家族です。

公開版の費用は作者の API キーから出ているので、今の形のまま広く使ってもらう想定にはしていません（[ADR 0012](../adr/0012-open-production-with-usage-limits.md)）。審査のあと（11/10 以降）に、ログインへ戻すか、上限と運用を作り直すかを決めます。当事者の評価もこれからなので、その結果も判断に入れます。続ける場合は、2027 年 8 月に変わる高額療養費の表の更新も要ります。

### 製品の中の Claude

`claude-sonnet-5-5` に、話の読み取りと言葉の部分を任せ、誤りが支払いに響く部分はプログラムに置きました。

| 担当       | すること                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| Claude     | 話から条件を読み取る。分からない値に仮の幅を置く。確かめる相手への質問文とカードの文章を書く。質問は、答えで結果が変わるときに 1 つだけ |
| プログラム | 金額と日付の計算。確かめることの順位。支払日の欄の見分け。引用と原文の照合。返答の金額と日付の照合。自分で直したカードの保護。持ち出す範囲の限定 |

- **構造化出力**: 返答とカードを Zod のスキーマで受け取ります。カードには、根拠にした発言の ID と原文の引用が必ず付きます。
- **道具（tool use）**: 高額療養費の上限、食事代、日付と営業日、支払いと入金の見通しの 4 つを道具にし、計算はそこだけで行います。範囲の外（表の期間外など）は計算せずに理由を返します。
- **引用の完全一致**: 引用が利用者の発言に文字列として無ければ、返答を捨てます。「残しておく言葉」は本文が引用と一致しなければ捨てます。AI が書いた思い出を本人の言葉として残さないためです。
- **金額の照合**: 返答に書かれた金額と日付を、道具の入出力・利用者の発言・出典つきの事実と照らし、見当たらなければ注意を出します。
- **順位と見分けもプログラム**: 何をまず確かめるかの順位は、確かめたときに幅がどれだけ縮むかでプログラムが決めます。支払日の 2 つの欄のどちらが「窓口で上限を使う」かも、見通しの支払いの額が高額療養費の計算の額と一致するかで、プログラムが見分けます。Claude が付けた名前では決めません。

この分担にしたのは、固定の入力欄では制度を知らない人が埋められず、計算を Claude に任せると誤りを見つけきれないからです。試作を実 API で動かしたとき、Claude は丸めた額（「5 万円ほど」）、自分で足した小計（175,880 円）、道具を通していない日付（1/31）を書きました。検査がこれらを指摘したので、指示を直しました。手術の成否や再発の確率を聞いた試験では、答えずに主治医に聞くことだと伝え、お金の話に戻りました。
