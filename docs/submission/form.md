## プロジェクト名

さきよみ — 家族のための準備室

## 選んだテーマ

## プロジェクトの概要

### 誰の、どんな課題か

入院が決まった人と、その家族の課題です。病院の見積もりを受け取っても、高額療養費（1 か月の医療費の自己負担に上限を設ける制度）が自分にいくら効くのか、入院が月をまたぐと何が変わるのか、給付金が支払いに間に合うのかは、制度を知らないと計算できません。同じ時期に、朝の支度や保険の確認を誰にどう頼むかも決めることになります。

公開の調査で分かっているのは次のことです。

- 過去 5 年に入院した人の自己負担は平均 18.7 万円で、収入が減った人も 18.3%（平均 27.3 万円）います。入院した 675 人のうち、高額療養費を使って窓口で上限までを払った人が 49.6%、いったん払って後から払い戻しを受けた人が 17.9% でした（[生命保険文化センター 2025 年度調査 p.60〜64](https://www.jili.or.jp/files/research/chousa/pdf/r7/2025honshi_all-.pdf)）。後払いの場合、協会けんぽは払い戻しまで[診療月から 3 か月以上](https://www.kyoukaikenpo.or.jp/faq/benefit/004/index.html)と案内しています。
- がんと診断されたとき働いていた 831 人の調査では、治療と仕事の両立で困難だったことの最多が「治療費が高い、治療費がいつ頃、いくらかかるか見通しが立たない」34.5% でした（[東京都 2014 年公表 概要版](https://www.gan-portal.metro.tokyo.lg.jp/uploads/01_260527_gaiyou.pdf)）。同じ調査で、傷病手当金を「知らなかったので、利用しなかった」人が 39.5% います（[資料編](https://www.gan-portal.metro.tokyo.lg.jp/uploads/08_siryouhen4.pdf)）。

これらは困りごとの存在を示す数字で、アプリで減らせる割合ではありません。東京都の調査は対象が限られ、2013 年の実施です。医療費の支払いに困った割合を直接問う厚生労働省の全国調査は見つかっていません。

### なぜ自分が取り組むのか

作者自身が入院の準備で、いくら要るのか、誰に何を頼むのかを整理しようとしたことが出発点です。

### 何を作り、何が変わるか

普通の言葉で話すと、いつ・いくら要るかの見通しと、家族や窓口に渡す文章ができる Web アプリを作りました。入力欄は 1 つで、制度の名前を知らなくても始められます。話した内容はカードになります。

- **お金の見通し**: Claude が話から条件を読み取り、プログラムが高額療養費の上限、食事代、営業日、手元資金の見通しを計算します。「1 週間延びたら」と話すと計算し直します。
- **暮らしの引き継ぎ**: 朝の支度など、本人が担っていることを渡せる文章にします。
- **確かめる・頼む**: 保険会社や身近な人に、そのまま見せられる質問文と依頼文を作ります。給付の可否は断定しません。
- **残しておく言葉**: 本人が話した言葉だけを、そのまま残します。

自分で直した文章は、話を続けても上書きされません。渡すものだけを選び、中身を確かめてからコピーか保存をします。送るのは本人です。

架空の例を一つ挙げます。2 週間の入院で医療費の総額が 80 万円、手元に 20 万円ある人の場合、退院の日に要る額は、窓口で上限が効けば 115,690 円、効かなければ 264,750 円で、後者は 64,750 円足りません。1 週間延びて月をまたぐと、上限は月ごとに掛かるので、総額が同じと仮定しても 127,240〜210,180 円に増えます（費用がすべて片方の月に寄る場合と半々の場合）。入院の前にこの差が見えれば、病院に何を確かめるかが決まります。

効果は確かめていません。当事者の評価は未実施で、確かめたのは、動くことと計算が合うことまでです。デモと公開データの人物と金額は、すべて架空です。

### ハッカソンのあと、誰が使い続けるか

入院は毎月起きることではないので、毎日開く道具にはしません。入院が決まってから、退院後の請求が終わるまでの数週間に使う道具です。最初に試してほしいのは、入院が決まった本人と、代わりに段取りを進める家族です。

公開版の費用は作者の API キーから出ているので、今の形のまま広く使ってもらう想定にはしていません（[ADR 0012](../adr/0012-open-production-with-usage-limits.md)）。審査のあと（11/10 以降）に、ログインへ戻すか、上限と運用を作り直すかを決めます。当事者の評価もこれからなので、その結果も判断に入れます。続ける場合は、2027 年 8 月に変わる高額療養費の表の更新も要ります。

### 製品の中の Claude

`claude-sonnet-5-5` に、話の読み取りと言葉の部分を任せ、誤りが支払いに響く部分はプログラムに置きました。

| 担当       | すること                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| Claude     | 話から条件を読み取る。分からない値に仮の幅を置く。カードの文章を書く。質問は、答えで結果が変わるときに 1 つだけ |
| プログラム | 金額と日付の計算。引用と原文の照合。返答の金額と日付の照合。自分で直したカードの保護。持ち出す範囲の限定        |

- **構造化出力**: 返答とカードを Zod のスキーマで受け取ります。カードには、根拠にした発言の ID と原文の引用が必ず付きます。
- **道具（tool use）**: 高額療養費の上限、食事代、日付と営業日、支払いと入金の見通しの 4 つを道具にし、計算はそこだけで行います。範囲の外（表の期間外など）は計算せずに理由を返します。
- **引用の完全一致**: 引用が利用者の発言に文字列として無ければ、返答を捨てます。「残しておく言葉」は本文が引用と一致しなければ捨てます。AI が書いた思い出を本人の言葉として残さないためです。
- **金額の照合**: 返答に書かれた金額と日付を、道具の入出力・利用者の発言・出典つきの事実と照らし、見当たらなければ注意を出します。

この分担にしたのは、固定の入力欄では制度を知らない人が埋められず、計算を Claude に任せると誤りを見つけきれないからです。試作を実 API で動かしたとき、Claude は丸めた額（「5 万円ほど」）、自分で足した小計（175,880 円）、道具を通していない日付（1/31）を書きました。検査がこれらを指摘したので、指示を直しました。手術の成否や再発の確率を聞いた試験では、答えずに主治医に聞くことだと伝え、お金の話に戻りました。
